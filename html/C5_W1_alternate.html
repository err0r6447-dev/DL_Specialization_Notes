1. Introduction: Why Sequence Models?

All the neural networks we have studied so far — logistic regression, fully connected networks, CNNs — take a fixed-size input and produce a fixed-size output. But many real-world problems involve sequences: ordered lists of items whose meaning depends on the order.

Consider the two sentences:

  • "He said, Teddy Roosevelt was a great President."
  • "He said, Teddy bears are on sale!"

Both start with "He said, Teddy" — but "Teddy" means a person in the first and an object in the second. A model must look at what comes after "Teddy" to decide. That is the essence of sequence modelling: the meaning of an item depends on its neighbours.

🟢 Intuition — Why Order Matters

Think of a sentence as a train of words. If you shuffle the carriages, the train still has the same carriages, but it is no longer the same train. "Dog bites man" and "Man bites dog" use identical words but mean very different things. Sequence models are designed to respect this ordering.

🟡 Important — Notation Convention

We use \(T_x\) to denote the length of the input sequence and \(T_y\) to denote the length of the output sequence. They may be equal or different depending on the task. The \(t\)-th element of a sequence is written with angle brackets: \(x^{\langle t \rangle}\). The parentheses notation \(x^{(i)}\) is reserved for the \(i\)-th training example.

2. Examples of Sequence Data

The lecture lists seven canonical examples. For each, note whether the input length \(T_x\) and output length \(T_y\) are the same, and what the "sequence" represents.

TaskInput \(x\)Output \(y\)\(T_x\) vs \(T_y\)
Speech recognition Audio waveform (sequence of samples) Transcribed words \(T_x \neq T_y\) (audio much longer)
Music generation Nothing / a starting note Sequence of notes \(T_x = 0\), \(T_y > 0\)
Sentiment classification Text (e.g., "There is nothing to like in this movie") Star rating (1–5) or positive/negative \(T_x > 0\), \(T_y = 1\)
DNA sequence analysis Nucleotide string (e.g., AGCCCCTGTGAGGAACTAG) Label per nucleotide or per sequence Depends
Machine translation Sentence in one language Sentence in another language \(T_x \neq T_y\)
Video activity recognition Sequence of video frames Action label (e.g., "Running") \(T_x > 0\), \(T_y = 1\)
Named entity recognition Sentence Label per word (person / not person) \(T_x = T_y\)
💡 Insight — One Framework, Many Tasks

All these tasks are instances of the same abstract problem: map a sequence (possibly empty) to another sequence (possibly of length 1). This is why RNNs are so powerful — the same architecture can be adapted to all of them.

4. Why Not a Standard Network?

Before building the RNN, it is worth understanding why a plain fully-connected network fails.

Figure 2. A naive fully connected approach: feed \(x^{\langle 1\rangle}, x^{\langle 2\rangle}, \dots, x^{\langle T_x\rangle}\) as a single wide input vector and predict all outputs at once. This has two fatal flaws (see below).

🔴 Warning — Two Fundamental Problems
  1. Variable length: Inputs and outputs can have different lengths in different examples (\(T_x\) and \(T_y\) vary), but a fully connected network expects a fixed-size input and produces a fixed-size output.
  2. No weight sharing across positions: The weights that recognize "Harry" at position 1 are completely different from the weights that would recognize "Harry" at position 5. The network cannot learn a general "Harry" detector — it must relearn it for every position. This is wasteful and does not generalize.
💡 Insight — What We Want Instead

We want a network that:

  • Processes the sequence one element at a time (so length is flexible).
  • Shares weights across time steps (so "Harry" is recognized the same way anywhere).
  • Maintains a memory of what it has seen so far, so the meaning of later words can depend on earlier ones.

That is exactly what an RNN does.

5. The Recurrent Neural Network Model

An RNN scans the input sequence from left to right. At each time step \(t\), it reads the current input \(x^{\langle t \rangle}\) and the hidden state \(a^{\langle t-1 \rangle}\) from the previous step. It produces a new hidden state \(a^{\langle t \rangle}\) and (optionally) an output \(\hat{y}^{\langle t \rangle}\).

Figure 3. An RNN "unrolled" over time. At each step, the current input \(x^{\langle t \rangle}\) and the previous hidden state \(a^{\langle t-1 \rangle}\) are combined to produce a new hidden state \(a^{\langle t \rangle}\) and output \(\hat{y}^{\langle t \rangle}\). The same weights \(W_{ax}, W_{aa}, W_{ya}\) (and biases) are used at every time step — this is the weight-sharing property that makes RNNs so powerful.

🔵 Definition — Hidden State \(a^{\langle t \rangle}\)

The hidden state (also called activation) \(a^{\langle t \rangle}\) is a vector that summarizes everything the RNN has seen up to time \(t\). It acts as the network's "memory." The initial hidden state \(a^{\langle 0 \rangle}\) is typically set to the zero vector.

🟢 Intuition — The RNN as a Reader

Imagine reading a sentence word by word and keeping a mental summary of what you've read so far. When you reach word 5, your mental summary (hidden state) already contains the gist of words 1–4. As you read each new word, you update your summary. An RNN works exactly this way.

6. Forward Propagation

At each time step \(t\), the RNN performs two computations:

$$a^{\langle t \rangle} = g_1\!\left( W_{aa}\, a^{\langle t-1 \rangle} + W_{ax}\, x^{\langle t \rangle} + b_a \right)$$
$$\hat{y}^{\langle t \rangle} = g_2\!\left( W_{ya}\, a^{\langle t \rangle} + b_y \right)$$

Let's unpack every symbol:

SymbolShapeMeaning
\(x^{\langle t \rangle}\)\(n_x \times 1\)Input at time \(t\) (e.g., one-hot word vector of size 10,000)
\(a^{\langle t \rangle}\)\(n_a \times 1\)Hidden state at time \(t\) (e.g., \(n_a = 100\))
\(W_{aa}\)\(n_a \times n_a\)Weight matrix mapping previous hidden state to current hidden state
\(W_{ax}\)\(n_a \times n_x\)Weight matrix mapping current input to current hidden state
\(W_{ya}\)\(n_y \times n_a\)Weight matrix mapping hidden state to output
\(b_a\)\(n_a \times 1\)Bias for the hidden state
\(b_y\)\(n_y \times 1\)Bias for the output
\(g_1\)—Activation function for hidden state — usually \(\tanh\) or ReLU
\(g_2\)—Activation for output — usually sigmoid (binary) or softmax (multi-class)
🟡 Important — Why \(\tanh\) for the Hidden State?

The hidden state can take both positive and negative values (it must be able to represent "the word is positive" or "the word is negative"), so \(\tanh\) (which outputs values in \([-1, 1]\)) is the traditional choice. ReLU is also used in some modern variants. The output activation depends on the task: sigmoid for binary classification, softmax for multi-class.

🟣 Example — Numerical Illustration (Small)

Suppose \(n_a = 2\), \(n_x = 2\), and at time \(t=1\):

  • \(a^{\langle 0 \rangle} = [0, 0]^T\)
  • \(x^{\langle 1 \rangle} = [1, 0]^T\)
  • \(W_{aa} = \begin{bmatrix} 0.1 & 0.2 \\ 0.3 & 0.4 \end{bmatrix}, \quad W_{ax} = \begin{bmatrix} 0.5 & 0.6 \\ 0.7 & 0.8 \end{bmatrix}, \quad b_a = [0.1, 0.1]^T\)

Then:

$$W_{aa}\,a^{\langle 0\rangle} + W_{ax}\,x^{\langle 1\rangle} + b_a = \begin{bmatrix} 0.5 + 0.1 \\ 0.7 + 0.1 \end{bmatrix} = \begin{bmatrix} 0.6 \\ 0.8 \end{bmatrix}$$

Applying \(\tanh\) element-wise gives:

$$a^{\langle 1 \rangle} = [\tanh(0.6), \tanh(0.8)] \approx [0.537, 0.664]$$

This activation is then passed forward to time \(t=2\) and also used to compute \(\hat{y}^{\langle 1 \rangle}\).

7. Simplified RNN Notation

The two weight matrices \(W_{aa}\) and \(W_{ax}\) always act together on the pair \((a^{\langle t-1 \rangle}, x^{\langle t \rangle})\). We can merge them into one matrix and stack the two inputs into one vector:

$$a^{\langle t \rangle} = g\!\left( W_a \begin{bmatrix} a^{\langle t-1 \rangle} \\ x^{\langle t \rangle} \end{bmatrix} + b_a \right)$$

where:

  • \(W_a = [\,W_{aa} \;\;|\;\; W_{ax}\,]\) — the concatenation of the two matrices along columns.
  • \(\begin{bmatrix} a^{\langle t-1 \rangle} \\ x^{\langle t \rangle} \end{bmatrix}\) — a vertical stack of the previous hidden state and current input.

Figure 4. The simplified notation stacks \(a^{\langle t-1\rangle}\) and \(x^{\langle t\rangle}\) into one vector and merges \(W_{aa}\) and \(W_{ax}\) into one matrix \(W_a\). It is mathematically equivalent but cleaner to write.

🔵 Remember — Simplified Forward Propagation
$$a^{\langle t \rangle} = g\!\left( W_a \begin{bmatrix} a^{\langle t-1 \rangle} \\ x^{\langle t \rangle} \end{bmatrix} + b_a \right)$$
$$\hat{y}^{\langle t \rangle} = g\!\left( W_y\, a^{\langle t \rangle} + b_y \right)$$

8. Backpropagation Through Time

Training an RNN is like training a regular neural network — we compute a loss, then compute gradients of the loss with respect to every parameter, then update the parameters with gradient descent. The twist is that the RNN is "unrolled" over time, so gradients must flow backwards through time as well as through layers. This is called Backpropagation Through Time (BPTT).

8.1 The Loss Function

At each time step \(t\), we compute a per-step loss. For binary classification (e.g., is the current word a person's name?), the loss is the logistic loss:

$$\mathcal{L}^{\langle t \rangle}\!\left(\hat{y}^{\langle t \rangle}, y^{\langle t \rangle}\right) = -\,y^{\langle t \rangle} \log \hat{y}^{\langle t \rangle} - \left(1 - y^{\langle t \rangle}\right) \log\!\left(1 - \hat{y}^{\langle t \rangle}\right)$$

The total loss over the whole sequence is simply the sum:

$$\mathcal{L}(\hat{y}, y) = \sum_{t=1}^{T_y} \mathcal{L}^{\langle t \rangle}\!\left(\hat{y}^{\langle t \rangle}, y^{\langle t \rangle}\right)$$
🔵 Definition — Loss Function

A loss function measures how wrong the network's prediction is compared to the true label. A lower loss means a better prediction. Training means adjusting the network's weights to reduce the loss.

8.2 The Backward Pass

Once the total loss is computed, we need \(\partial \mathcal{L} / \partial W\) for every weight. Because the hidden states are chained (\(a^{\langle t \rangle}\) depends on \(a^{\langle t-1 \rangle}\), which depends on \(a^{\langle t-2 \rangle}\), …), we apply the chain rule across time.

Figure 5. Forward propagation (blue) flows left to right, computing \(a^{\langle t \rangle}\) and \(\hat{y}^{\langle t \rangle}\). Backpropagation through time (red) flows right to left, computing gradients of the total loss with respect to each weight matrix. The same weights are shared across time, so gradients from all time steps accumulate before the weights are updated.

💡 Insight — Why "Through Time"?

In a normal feedforward network, backprop travels backwards through layers. In an RNN, the "layers" are the same layer reused at different time steps. Backprop still flows backwards, but now it flows through time steps instead of distinct layers. Hence the name.

9. Different Types of RNNs

Not all sequence problems have \(T_x = T_y\). RNNs can be adapted to many shapes by choosing which time steps produce output and which consume input.

Figure 6. Five common RNN architectures. A single architecture can be adapted by controlling which time steps receive input and which produce output. One-to-one is standard; one-to-many is music generation; many-to-one is sentiment classification; many-to-many (Tx=Ty) is named entity recognition; many-to-many (Tx≠Ty) is machine translation, which uses an encoder to read the input and a decoder to generate the output.

🟡 Important — Task ↔ Architecture
  • One-to-one: standard neural network (not really an RNN).
  • One-to-many: music generation (input = genre or starting note, output = melody).
  • Many-to-one: sentiment classification (input = text, output = rating).
  • Many-to-many (Tx = Ty): named entity recognition (input = words, output = label per word).
  • Many-to-many (Tx ≠ Ty): machine translation (input = French sentence, output = English sentence). Uses an encoder RNN to read the input and a decoder RNN to generate the output.

10. Language Modelling & Sequence Generation

10.1 What Is a Language Model?

A language model estimates the probability that a given sequence of words is a valid sentence in a language. This is useful for:

  • Speech recognition: distinguishing "The apple and pear salad" from "The apple and pair salad." Both sound similar, but the first is far more probable English.
  • Machine translation: picking the most fluent translation among candidates.
  • Text generation: generating new text one word at a time.
🟣 Example — Why Probabilities Matter

If a speech recognizer hears a garbled phrase that could be either:

  • "The apple and pair salad" — \(P = 3.2 \times 10^{-13}\)
  • "The apple and pear salad" — \(P = 5.7 \times 10^{-10}\)

A language model ranks the second one much higher, so the recognizer picks "pear salad."

10.2 Training an RNN Language Model

Given a large corpus of English text, we train an RNN to predict the next word at every position.

Figure 7. RNN language model. Given the words so far, the RNN predicts a probability distribution over the entire vocabulary for the next word. At step \(t\), the input is the previous word \(y^{\langle t-1 \rangle}\) (or \(x^{\langle 1\rangle}\) for the first step), and the target is the next word \(y^{\langle t \rangle}\).

10.3 The Output Distribution

At each time step, the RNN produces:

$$\hat{y}^{\langle t \rangle} = \text{softmax}\!\left(W_y\, a^{\langle t \rangle} + b_y\right)$$

\(\hat{y}^{\langle t \rangle}\) is a vector of length \(|V|\), where each entry is the probability that the next word is the corresponding vocabulary word.

10.4 The Loss

The per-step loss is cross-entropy over the vocabulary:

$$\mathcal{L}^{\langle t \rangle}\!\left(\hat{y}^{\langle t \rangle}, y^{\langle t \rangle}\right) = -\sum_{i=1}^{|V|} y_i^{\langle t \rangle} \log \hat{y}_i^{\langle t \rangle}$$

Total loss is the sum over time steps:

$$\mathcal{L}(\hat{y}, y) = \sum_{t=1}^{T_y} \mathcal{L}^{\langle t \rangle}\!\left(\hat{y}^{\langle t \rangle}, y^{\langle t \rangle}\right)$$

10.5 The Special Tokens

  • <EOS> ("end of sentence"): marks the end of a sequence. The model must learn to output this token to signal completion.
  • <UNK> ("unknown"): represents any word not in the vocabulary.
🔵 Remember — Sequence Probability

The language model lets us compute:

$$P(y^{\langle 1 \rangle}, y^{\langle 2 \rangle}, \dots, y^{\langle T_y \rangle}) = \prod_{t=1}^{T_y} P\!\left(y^{\langle t \rangle} \mid y^{\langle 1 \rangle}, \dots, y^{\langle t-1 \rangle}\right)$$

This is the chain rule of probability — the probability of the whole sentence is the product of each word's probability given all previous words.

11. Sampling Novel Sequences

Once an RNN language model is trained, we can use it to generate new text. This is called sampling.

11.1 The Sampling Procedure

  1. Start with \(a^{\langle 0 \rangle} = \vec{0}\) and \(x^{\langle 1 \rangle} = \vec{0}\).
  2. Run the RNN to get \(\hat{y}^{\langle 1 \rangle}\), a probability distribution over the vocabulary.
  3. Randomly sample one word from this distribution using np.random.choice.
  4. Feed the sampled word as the input to the next time step.
  5. Repeat until the model outputs <EOS> or a preset maximum length is reached.
🟡 Important — Training vs. Sampling
  • Training: the input at step \(t\) is the true previous word (from the training data).
  • Sampling: the input at step \(t\) is the model's own previous output. Errors can therefore compound.

Figure 8. Training vs. sampling. During training, the true previous word is fed as input. During sampling, the model's own previously-sampled word is fed back as input. The blue curved arrows show this feedback loop.

11.2 Character-Level Language Models

Instead of words, we can build a language model where each character is a token. The vocabulary is then small (letters, digits, punctuation — maybe 50–100 tokens).

🟣 Example — Character-Level Model Output

A character-level model trained on Shakespeare can generate text like:

"The mortal moon hath her eclipse in love.
And subject of this thou art another this fold.
When besser be my love to me see sabl's.
For whose are ruse of mine eyes heaves."

It is not real Shakespeare, but it has learned spelling, spacing, and some stylistic patterns. This kind of model is also used for generating syntactically plausible but nonsensical words (e.g., "Zaboomafoo").

12. Vanishing Gradients with RNNs

Plain RNNs have a serious training problem: as sequences get long, gradients tend to vanish (or occasionally explode) as they flow backwards through many time steps.

🔵 Definition — Vanishing Gradient

During backpropagation, the gradient of the loss with respect to early time steps is computed by multiplying together many small derivative terms (one per time step). If those terms are consistently less than 1, their product shrinks toward zero — the gradient "vanishes," and the network cannot learn long-range dependencies.

🟢 Intuition — Passing a Whisper

Imagine a game of telephone with 50 people. Each person whispers what they heard to the next. By the end, the message is garbled or lost. The same happens to gradients in a long RNN: each "pass" multiplies the signal by a number slightly less than 1, and after 50 steps the signal is effectively zero.

🟣 Example — Why It Matters

Sentence: "The cat, which already ate a full meal, was full."

The subject is singular ("cat"), so the verb must be "was" (not "were"). To get this right, the network must remember information from many time steps earlier. With a plain RNN, that information may have vanished.

🔴 Warning — Exploding Gradients Too

If the derivative terms are consistently greater than 1, the product grows exponentially — an exploding gradient. This can make training diverge. A common fix is gradient clipping (rescale gradients if their norm exceeds a threshold). Vanishing gradients are harder to fix and motivated the GRU and LSTM.

💡 Insight — What GRU and LSTM Fix

GRUs and LSTMs add gates that control how much information flows between time steps. These gates let the network preserve important information over many steps — the gradient can flow through a "highway" without being repeatedly multiplied by small numbers.

13. Gated Recurrent Unit (GRU)

The GRU (Cho et al., 2014) modifies the RNN cell so that it can selectively remember or forget information. It uses a memory cell \(c^{\langle t \rangle}\) and an update gate \(\Gamma_u\) to control the flow.

13.1 Intuition

🟢 Intuition — A Gate That Decides What to Remember

Imagine reading a long sentence and deciding after each word: "Should I remember this, or overwrite my memory with new content?" The GRU's update gate \(\Gamma_u\) is exactly that decision — a number between 0 and 1 that says how much of the previous memory to keep and how much of the new candidate to write in.

13.2 The Simplified GRU Equations

First, we compute a candidate memory \(\tilde{c}^{\langle t \rangle}\) — the new information we might write into memory:

$$\tilde{c}^{\langle t \rangle} = \tanh\!\left( W_c \begin{bmatrix} c^{\langle t-1 \rangle} \\ x^{\langle t \rangle} \end{bmatrix} + b_c \right)$$

Then we compute the update gate \(\Gamma_u\):

$$\Gamma_u = \sigma\!\left( W_u \begin{bmatrix} c^{\langle t-1 \rangle} \\ x^{\langle t \rangle} \end{bmatrix} + b_u \right)$$

Finally, we blend the old memory with the candidate:

$$c^{\langle t \rangle} = \Gamma_u \ast \tilde{c}^{\langle t \rangle} + \left(1 - \Gamma_u\right) \ast c^{\langle t-1 \rangle}$$
$$a^{\langle t \rangle} = c^{\langle t \rangle}$$

where:

  • \(\tilde{c}^{\langle t \rangle}\) — candidate memory (what we could write).
  • \(c^{\langle t \rangle}\) — actual memory (what we do write).
  • \(\Gamma_u\) — update gate, a vector of values in \((0, 1)\) (element-wise sigmoid).
  • \(\ast\) — element-wise multiplication.
  • \(\sigma\) — sigmoid function, squashing values to \((0, 1)\).
🟡 Important — What the Gate Does
  • If \(\Gamma_u \approx 1\): keep the candidate \(\tilde{c}^{\langle t \rangle}\) — overwrite the old memory.
  • If \(\Gamma_u \approx 0\): keep the old memory \(c^{\langle t-1 \rangle}\) — do not update.
  • Intermediate values: partially blend old and new.

This lets information persist over many time steps when \(\Gamma_u\) stays near 0 — this is what solves the vanishing gradient problem.

13.3 The Full GRU

The full GRU adds a relevance gate \(\Gamma_r\) that controls how much of the previous memory is used when computing the candidate:

$$\tilde{c}^{\langle t \rangle} = \tanh\!\left( W_c \begin{bmatrix} \Gamma_r \ast c^{\langle t-1 \rangle} \\ x^{\langle t \rangle} \end{bmatrix} + b_c \right)$$
$$\Gamma_u = \sigma\!\left( W_u \begin{bmatrix} c^{\langle t-1 \rangle} \\ x^{\langle t \rangle} \end{bmatrix} + b_u \right)$$
$$\Gamma_r = \sigma\!\left( W_r \begin{bmatrix} c^{\langle t-1 \rangle} \\ x^{\langle t \rangle} \end{bmatrix} + b_r \right)$$
$$c^{\langle t \rangle} = \Gamma_u \ast \tilde{c}^{\langle t \rangle} + \left(1 - \Gamma_u\right) \ast c^{\langle t-1 \rangle}$$
$$a^{\langle t \rangle} = c^{\langle t \rangle}$$
🔵 Remember — GRU in One Sentence

The GRU keeps a memory cell \(c^{\langle t \rangle}\) and uses gates to decide how much of the old memory to keep and how much of the newly-computed candidate to write in.

14. LSTM (Long Short-Term Memory)

The LSTM (Hochreiter & Schmidhuber, 1997) is a more powerful and more general version of the GRU. It has three gates instead of two and separates the memory cell \(c^{\langle t \rangle}\) from the hidden state \(a^{\langle t \rangle}\).

14.1 The Three Gates

  • Update gate \(\Gamma_u\): how much of the new candidate to write into memory.
  • Forget gate \(\Gamma_f\): how much of the old memory to keep (as opposed to discard).
  • Output gate \(\Gamma_o\): how much of the memory to expose as the hidden state \(a^{\langle t \rangle}\).

14.2 The Equations

Candidate memory:

$$\tilde{c}^{\langle t \rangle} = \tanh\!\left( W_c \begin{bmatrix} a^{\langle t-1 \rangle} \\ x^{\langle t \rangle} \end{bmatrix} + b_c \right)$$

Three gates (each is a sigmoid):

$$\Gamma_u = \sigma\!\left( W_u \begin{bmatrix} a^{\langle t-1 \rangle} \\ x^{\langle t \rangle} \end{bmatrix} + b_u \right)$$
$$\Gamma_f = \sigma\!\left( W_f \begin{bmatrix} a^{\langle t-1 \rangle} \\ x^{\langle t \rangle} \end{bmatrix} + b_f \right)$$
$$\Gamma_o = \sigma\!\left( W_o \begin{bmatrix} a^{\langle t-1 \rangle} \\ x^{\langle t \rangle} \end{bmatrix} + b_o \right)$$

Update memory:

$$c^{\langle t \rangle} = \Gamma_u \ast \tilde{c}^{\langle t \rangle} + \Gamma_f \ast c^{\langle t-1 \rangle}$$

Update hidden state:

$$a^{\langle t \rangle} = \Gamma_o \ast \tanh\!\left(c^{\langle t \rangle}\right)$$

Figure 9. The LSTM cell. The red horizontal line is the memory cell state \(c^{\langle t \rangle}\), which flows forward with only minor transformations (forget-gate multiply and update-gate add). This "memory highway" is why gradients can flow over long sequences without vanishing. The three sigmoid gates decide what to forget, what to update, and what to output.

💡 Insight — Which One to Use?

Andrew Ng recommends: "The LSTM is historically more proven, but the GRU is simpler and often just as good. Try both on your task." In practice, LSTMs tend to be the safer default; GRUs are preferred when compute budget or dataset size is limited.

15. Bidirectional RNN

So far, our RNNs have processed the sequence left to right. But sometimes the meaning of a word depends on words that come after it.

🟣 Example — Information From the Future
  • "He said, Teddy bears are on sale!"
  • "He said, Teddy Roosevelt was a great President!"

To decide whether "Teddy" is a person's name, the model needs to know what comes after "Teddy". A left-to-right RNN cannot do this at the moment it reads "Teddy."

15.1 The Bidirectional RNN Architecture

A Bidirectional RNN (BRNN) runs two RNNs — one left-to-right and one right-to-left — and combines their hidden states at every time step.

Figure 10. A Bidirectional RNN. The green cells process the sequence left-to-right; the red cells process it right-to-left. At each time step, both hidden states are combined to produce \(\hat{y}^{\langle t \rangle}\). This gives each output access to both past and future context.

🟡 Important — BRNN Needs the Full Sequence

A bidirectional RNN can only be used when you have the entire input sequence before producing any output. It is unsuitable for real-time generation (where the future is not yet known), but excellent for tasks like named entity recognition, where the whole sentence is available.

16. Deep RNNs

Just as we can stack layers in a feedforward network, we can stack RNN layers. The output of one RNN layer becomes the input of the next.

Figure 11. A deep RNN with three stacked layers. Each layer processes the sequence left-to-right, and the output of layer \(l\) at time \(t\) becomes the input of layer \(l+1\) at time \(t\). The vertical arrows represent the layer-to-layer connections.

🟡 Important — How Deep Can We Go?

Unlike CNNs, which can have 100+ layers, deep RNNs are usually only 3 layers deep. The reason is that each layer already processes the entire sequence, so adding more layers multiplies the sequence-length factor and makes training very expensive. 3 layers is typically enough; sometimes a deeper feedforward network is stacked on top of the final RNN output.

16.1 The Deep RNN Equation

For layer \(l\) at time step \(t\):

$$a^{[l]\langle t \rangle} = g\!\left( W_a^{[l]} \begin{bmatrix} a^{[l]\langle t-1 \rangle} \\ a^{[l-1]\langle t \rangle} \end{bmatrix} + b_a^{[l]} \right)$$

Here, the input to layer \(l\) at time \(t\) is the output of layer \(l-1\) at time \(t\) (denoted \(a^{[l-1]\langle t \rangle}\)).

17. Weekly Summary

This week introduced the foundational ideas of sequence modelling and RNNs. Here is the full picture:

  • Sequence data is everywhere — speech, text, DNA, music, video. Its defining feature is that order matters.
  • One-hot vectors are the simplest way to represent words, but they carry no similarity information.
  • A plain fully-connected network fails on sequences because it cannot handle variable lengths and cannot share weights across positions.
  • An RNN processes the sequence one step at a time, sharing weights across time steps and maintaining a hidden state \(a^{\langle t \rangle}\) that acts as memory.
  • Forward propagation at each step: \(a^{\langle t \rangle} = g(W_a [a^{\langle t-1\rangle}, x^{\langle t\rangle}] + b_a)\), \(\hat{y}^{\langle t \rangle} = g(W_y a^{\langle t\rangle} + b_y)\).
  • Backpropagation through time (BPTT) flows gradients backwards through time as well as layers.
  • RNNs can be arranged in five shapes: one-to-one, one-to-many, many-to-one, many-to-many (Tx=Ty), and many-to-many (Tx≠Ty, encoder-decoder).
  • Language models estimate the probability of a sequence and can be used to generate new text via sampling.
  • Vanishing gradients prevent plain RNNs from learning long-range dependencies.
  • GRUs use a memory cell and two gates to control information flow.
  • LSTMs extend this with three gates (update, forget, output) and a separate hidden state.
  • Bidirectional RNNs read the sequence in both directions, giving each output access to past and future context.
  • Deep RNNs stack multiple RNN layers — usually 3 layers is enough.

19. Important Equations (Reference)

🔵 1. Forward Propagation — Basic RNN
$$a^{\langle t \rangle} = g_1\!\left( W_{aa}\, a^{\langle t-1 \rangle} + W_{ax}\, x^{\langle t \rangle} + b_a \right)$$
$$\hat{y}^{\langle t \rangle} = g_2\!\left( W_{ya}\, a^{\langle t \rangle} + b_y \right)$$
🔵 2. Simplified Forward Propagation
$$a^{\langle t \rangle} = g\!\left( W_a \begin{bmatrix} a^{\langle t-1 \rangle} \\ x^{\langle t \rangle} \end{bmatrix} + b_a \right)$$
$$\hat{y}^{\langle t \rangle} = g\!\left( W_y\, a^{\langle t \rangle} + b_y \right)$$
🔵 3. Per-Step Loss
$$\mathcal{L}^{\langle t \rangle}(\hat{y}^{\langle t \rangle}, y^{\langle t \rangle}) = -y^{\langle t \rangle}\log\hat{y}^{\langle t \rangle} - (1-y^{\langle t \rangle})\log(1-\hat{y}^{\langle t \rangle})$$
🔵 4. Total Loss
$$\mathcal{L}(\hat{y}, y) = \sum_{t=1}^{T_y} \mathcal{L}^{\langle t \rangle}(\hat{y}^{\langle t \rangle}, y^{\langle t \rangle})$$
🔵 5. GRU (Simplified)
$$\tilde{c}^{\langle t \rangle} = \tanh\!\left( W_c \begin{bmatrix} c^{\langle t-1 \rangle} \\ x^{\langle t \rangle} \end{bmatrix} + b_c \right)$$
$$\Gamma_u = \sigma\!\left( W_u \begin{bmatrix} c^{\langle t-1 \rangle} \\ x^{\langle t \rangle} \end{bmatrix} + b_u \right)$$
$$c^{\langle t \rangle} = \Gamma_u \ast \tilde{c}^{\langle t \rangle} + (1-\Gamma_u) \ast c^{\langle t-1 \rangle}$$
$$a^{\langle t \rangle} = c^{\langle t \rangle}$$
🔵 6. LSTM
$$\tilde{c}^{\langle t \rangle} = \tanh\!\left( W_c \begin{bmatrix} a^{\langle t-1 \rangle} \\ x^{\langle t \rangle} \end{bmatrix} + b_c \right)$$
$$\Gamma_u = \sigma\!\left( W_u \begin{bmatrix} a^{\langle t-1 \rangle} \\ x^{\langle t \rangle} \end{bmatrix} + b_u \right),\quad \Gamma_f = \sigma\!\left( W_f \begin{bmatrix} a^{\langle t-1 \rangle} \\ x^{\langle t \rangle} \end{bmatrix} + b_f \right)$$
$$\Gamma_o = \sigma\!\left( W_o \begin{bmatrix} a^{\langle t-1 \rangle} \\ x^{\langle t \rangle} \end{bmatrix} + b_o \right)$$
$$c^{\langle t \rangle} = \Gamma_u \ast \tilde{c}^{\langle t \rangle} + \Gamma_f \ast c^{\langle t-1 \rangle}$$
$$a^{\langle t \rangle} = \Gamma_o \ast \tanh(c^{\langle t \rangle})$$
🔵 7. Deep RNN Layer Equation
$$a^{[l]\langle t \rangle} = g\!\left( W_a^{[l]} \begin{bmatrix} a^{[l]\langle t-1 \rangle} \\ a^{[l-1]\langle t \rangle} \end{bmatrix} + b_a^{[l]} \right)$$

21. Quick Review (Q&A)

Click each question to reveal its answer.

Q1. What is the difference between \(x^{\langle t \rangle}\) and \(x^{(i)}\)?

\(x^{\langle t \rangle}\) is the input at time step \(t\) in a sequence (e.g., the 3rd word of a sentence). \(x^{(i)}\) is the \(i\)-th training example. They use different brackets to avoid confusion.

Q2. Why can't a standard fully-connected network handle sequences well?

Two reasons: (1) inputs and outputs have variable lengths, but fully-connected networks expect fixed sizes; (2) they cannot share weights across positions of the sequence, so they cannot learn a general "word detector" that works anywhere in the sequence.

Q3. What is the hidden state \(a^{\langle t \rangle}\), and why is it important?

The hidden state is a vector that summarizes everything the RNN has seen up to time \(t\). It acts as the network's memory, allowing the meaning of later elements to depend on earlier ones.

Q4. Write down the simplified RNN forward-propagation equations.

\(a^{\langle t \rangle} = g(W_a [a^{\langle t-1 \rangle}; x^{\langle t \rangle}] + b_a)\)

\(\hat{y}^{\langle t \rangle} = g(W_y\, a^{\langle t \rangle} + b_y)\)

where \([a; x]\) denotes vertical concatenation, and \(g\) is the activation function (\(\tanh\) for the hidden state, sigmoid or softmax for the output).

Q5. What is backpropagation through time?

It is the process of computing gradients of the loss with respect to the RNN's weights by applying the chain rule across both layers and time steps. Because the same weights are shared at every time step, their gradients accumulate from all time steps before the parameter update.

Q6. List the five types of RNN architectures and give one application of each.
  • One-to-one: standard classification (not really sequence).
  • One-to-many: music generation.
  • Many-to-one: sentiment classification.
  • Many-to-many (Tx=Ty): named entity recognition.
  • Many-to-many (Tx≠Ty): machine translation (encoder-decoder).
Q7. What is a language model, and what is it used for?

A language model estimates the probability of a sequence of words. It is used in speech recognition (to disambiguate similar-sounding phrases), machine translation (to pick fluent output), and text generation.

Q8. How does sampling work during text generation?

Starting from \(a^{\langle 0 \rangle} = \vec{0}\) and \(x^{\langle 1 \rangle} = \vec{0}\), the RNN produces a probability distribution over the vocabulary at each step. We randomly sample one word from this distribution and feed it back as the input to the next time step. This continues until <EOS> or a max length is reached.

Q9. What is the difference between word-level and character-level language models?

Word-level models have large vocabularies (10,000+) and shorter sequences. Character-level models have small vocabularies (~50–100 tokens) and much longer sequences. Character-level models are more robust to rare words but usually produce text with less long-range coherence.

Q10. Why do plain RNNs suffer from vanishing gradients?

During backprop, gradients are multiplied by a chain of derivative terms (one per time step). If those terms are consistently less than 1, their product shrinks to zero. After many time steps, the gradient to early steps is effectively zero — the network cannot learn long-range dependencies.

Q11. What does the update gate \(\Gamma_u\) in a GRU control?

It controls how much of the newly computed candidate memory \(\tilde{c}^{\langle t \rangle}\) to write into memory. If \(\Gamma_u \approx 1\), the candidate overwrites the old memory. If \(\Gamma_u \approx 0\), the old memory is preserved.

Q12. What are the three gates in an LSTM, and what does each do?
  • Update gate \(\Gamma_u\): how much of the new candidate to write into memory.
  • Forget gate \(\Gamma_f\): how much of the old memory to keep.
  • Output gate \(\Gamma_o\): how much of the memory to expose as the hidden state \(a^{\langle t \rangle}\).
Q13. What is the key difference between GRU and LSTM?

LSTM has three gates (update, forget, output) and a separate hidden state \(a\) and memory cell \(c\). GRU has only two gates (update, relevance) and sets \(a = c\). LSTM is more expressive, GRU is simpler and faster.

Q14. Why is a bidirectional RNN useful, and when can't you use one?

It processes the sequence both left-to-right and right-to-left, giving each output access to past and future context. This is useful for named entity recognition, where the meaning of a word can depend on words after it. You cannot use it for real-time generation (where the future is unknown) or when the entire input must be streamed.

Q15. How deep are deep RNNs usually, and why not deeper?

Usually 3 layers. Each layer already processes the whole sequence, so adding layers multiplies the sequence-length factor and makes training very expensive. Deeper than 3 rarely helps.

Q16. How is the initial hidden state \(a^{\langle 0 \rangle}\) usually set?

To the zero vector. It can also be learned as a parameter, but zero initialization is the standard choice.

Q17. What is the role of the <EOS> token?

<EOS> (End Of Sentence) marks the end of a sequence. During training, the model learns to output it at the end; during sampling, it tells the generator to stop.

Q18. Why is the softmax output at each time step a vector of length |V|?

Because the model is predicting the probability of the next word among all possible words in the vocabulary. Each entry in the vector is the probability of the corresponding word being the next one.

Q19. What is the total loss for an RNN sequence model?

The sum of per-step losses: \(\mathcal{L} = \sum_{t=1}^{T_y} \mathcal{L}^{\langle t \rangle}\). Alternatively, the average can be used. During backprop, gradients from all time steps are accumulated.

Q20. In an LSTM, why is the memory cell \(c^{\langle t \rangle}\) called a "highway"?

Because the memory cell passes through time with only two simple operations — a multiply by \(\Gamma_f\) and an add of \(\Gamma_u \ast \tilde{c}^{\langle t \rangle}\) — which are both near-identity if the gates are near 1 and 0. This lets gradients flow over many time steps without vanishing, unlike the many-multiplication path in a plain RNN.

22. Self-Test

Conceptual questions from easy → hard. Click to reveal.

Easy

ST1. Name three real-world applications of sequence models.

Any three of: speech recognition, music generation, sentiment classification, DNA sequence analysis, machine translation, video activity recognition, named entity recognition.

ST2. What is the difference between \(T_x\) and \(T_y\)?

\(T_x\) is the length of the input sequence; \(T_y\) is the length of the output sequence. They can be equal (e.g., named entity recognition) or different (e.g., machine translation).

ST3. What activation function is typically used for the hidden state, and why?

\(\tanh\) is typically used because the hidden state needs to be able to take both positive and negative values (representing "the word is positive" or "negative" about some feature), and \(\tanh\) outputs in \([-1, 1]\). ReLU is also sometimes used in modern variants.

Medium

ST4. Explain why the same weights \(W_{aa}, W_{ax}, W_{ya}\) are used at every time step. What would go wrong if each time step had its own weights?

Sharing weights lets the network learn a general "how to update memory from input and previous memory" function that works regardless of position. If each time step had its own weights, the network would have to relearn patterns at every position — wasteful, impossible for variable-length sequences, and unable to generalize to new positions.

ST5. A training example has \(T_x = 5\) and \(T_y = 5\). Which RNN architecture types are consistent with this?

Many-to-many (Tx = Ty), like named entity recognition. Also many-to-one if only the last step outputs, or one-to-many if only the first step receives input. The shapes \(T_x = T_y = 5\) are compatible with several architectures — the choice depends on the task.

ST6. During sampling, why must you use the model's own output as the next input instead of the true next word?

Because at generation time, the true next word is not available (you're generating new text, not evaluating on a fixed dataset). The model must generate the next word based on what it has generated so far. This is why errors can compound — an early mistake propagates into later steps.

ST7. Give a concrete example where a bidirectional RNN outperforms a unidirectional RNN.

Named entity recognition: "He said, 'Teddy bears are on sale!'" vs. "He said, 'Teddy Roosevelt was a great President!'" To decide whether "Teddy" is part of a person's name, the model needs the following word ("bears" vs. "Roosevelt"). A unidirectional left-to-right RNN cannot use this future information; a bidirectional RNN can.

Hard

ST8. Derive the intuition for why the LSTM's memory highway helps with vanishing gradients.

In a plain RNN, the gradient at time \(t\) with respect to time \(t-k\) is a product of \(k\) Jacobian matrices. If each matrix's spectral norm is less than 1, the product vanishes. In an LSTM, the memory cell update is \(c^{\langle t \rangle} = \Gamma_f \ast c^{\langle t-1 \rangle} + \Gamma_u \ast \tilde{c}^{\langle t \rangle}\). The gradient of \(c^{\langle t \rangle}\) with respect to \(c^{\langle t-1 \rangle}\) is essentially \(\Gamma_f\) — a diagonal matrix of gate values in \((0,1)\). When \(\Gamma_f \approx 1\), this gradient is close to the identity, so the gradient can flow backwards through time without shrinking. The model learns when to open or close this highway via the gates.

ST9. Suppose you train an RNN language model on English text. Why does the model sometimes generate sentences that are grammatically correct but semantically nonsense?

Because the model learns the statistical patterns of the training text (what word tends to follow what), not the underlying semantics. It can produce locally plausible sequences (grammar) without maintaining global coherence (meaning), especially for longer passages. Character-level models are especially prone to this, since they have less context per token.

ST10. In the LSTM equations, why is \(\Gamma_f\) used as the coefficient of \(c^{\langle t-1 \rangle}\) and \(\Gamma_u\) as the coefficient of \(\tilde{c}^{\langle t \rangle}\), rather than the other way around?

Both gates are sigmoids in (0,1), so the roles are conventional. The convention is that \(\Gamma_f\) ("forget gate") controls how much of the old memory to keep, and \(\Gamma_u\) ("update gate") controls how much of the new candidate to write in. Note that in the GRU, the corresponding gate is written as \(\Gamma_u\) for the new candidate and \((1-\Gamma_u)\) for the old memory — the GRU uses a single complementary gate, while the LSTM has two independent gates. This extra independence (two separate gates) is what makes the LSTM more expressive.

ST11. Why does the deep RNN equation have \(a^{[l-1]\langle t \rangle}\) as part of its input, rather than \(x^{\langle t \rangle}\)?

Because layer \(l\) receives input from the layer below it, at the same time step. Layer 1 receives \(x^{\langle t \rangle}\); layer 2 receives the output of layer 1 at time \(t\), which is \(a^{[1]\langle t \rangle}\); in general layer \(l\) receives \(a^{[l-1]\langle t \rangle}\).

ST12. A student says: "Bidirectional RNNs are always better than unidirectional RNNs because they see more information." Critique this claim.

The claim is false in general. Bidirectional RNNs require the entire input sequence before producing any output, which is impossible in online or real-time settings (e.g., streaming speech recognition, autoregressive text generation). They also cost roughly twice as much compute and memory. For offline tasks like named entity recognition or translation, they do outperform unidirectional RNNs — but the trade-off must be considered for each task.
