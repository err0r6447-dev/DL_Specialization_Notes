1. From Logistic Regression to a Neural Network

In Week 2, we built logistic regression: a single computational unit that takes inputs $x_1, x_2, x_3$, computes $z = w^Tx + b$, applies a sigmoid, and produces $\hat{y} = a = \sigma(z)$. It's a “one-neuron network.”

This week, we take the natural next step: stack neurons into layers. The result is a real neural network with a hidden layer between the input and the output.

🟢 Intuition — why add a hidden layer?

A single neuron can only learn a limited family of decision boundaries (essentially linear ones, after the sigmoid transform). By stacking neurons into layers, the network can first compute intermediate features (the hidden layer's activations) and then combine them into a final decision. This is what lets neural networks learn much more complex patterns than logistic regression.

⭐ Key Idea

A "2-layer neural network" in this course means: input layer → hidden layer → output layer. The input layer is not counted as a "layer" because it just passes the raw data through. So a network with one hidden layer is called a "2-layer NN": layer 1 is the hidden layer, layer 2 is the output layer.

2. Neural Network Representation

Let's formalize the notation for a 2-layer network with 3 inputs and 4 hidden units.

2.1 Notation for the 2-layer network

SymbolMeaningShape (for our 3-4-1 network)
$x$Input feature vector$(3, 1)$
$a^{[0]}$Activation of layer 0 (= $x$)$(3, 1)$
$W^{[1]}$Weight matrix, layer 1$(4, 3)$ — 4 hidden units × 3 inputs
$b^{[1]}$Bias vector, layer 1$(4, 1)$ — one per hidden unit
$z^{[1]}$Pre-activation, layer 1$(4, 1)$
$a^{[1]}$Activation (output), layer 1$(4, 1)$
$W^{[2]}$Weight matrix, layer 2$(1, 4)$ — 1 output unit × 4 hidden units
$b^{[2]}$Bias, layer 2$(1, 1)$ — a scalar
$z^{[2]}$Pre-activation, layer 2$(1, 1)$
$a^{[2]} = \hat{y}$Final prediction$(1, 1)$
💡 Insight — why $W^{[l]}$ has this shape

In general, $W^{[l]}$ has shape $(\text{units in layer } l) \times (\text{units in layer } l-1)$. So $W^{[1]}$ is $(4, 3)$ because layer 1 has 4 units and layer 0 (input) has 3. And $W^{[2]}$ is $(1, 4)$ because layer 2 has 1 unit and layer 1 has 4. This shape convention is what makes the forward-pass matrix multiplications work out cleanly.

3. Computing a Neural Network's Output

How does a shallow neural network compute its output from an input? By forward propagation — information flows from input to hidden layer to output layer.

3.1 A single hidden unit

Each hidden unit is essentially a mini logistic regression:

$$z_1^{[1]} = w_1^{[1]T} x + b_1^{[1]}, \quad a_1^{[1]} = \sigma(z_1^{[1]})$$

Here $w_1^{[1]}$ is the weight vector for the first hidden unit, and $b_1^{[1]}$ its bias. The superscript $[1]$ means "layer 1."

Doing this for all 4 hidden units simultaneously (as a matrix-vector product):

$$z^{[1]} = W^{[1]} x + b^{[1]}, \quad a^{[1]} = \sigma(z^{[1]})$$

Then the output layer computes:

$$z^{[2]} = W^{[2]} a^{[1]} + b^{[2]}, \quad a^{[2]} = \sigma(z^{[2]}) = \hat{y}$$
💡 Insight — deep learning is composition

Notice the structure: a neural network is just a composition of linear transforms ($W x + b$) and element-wise non-linearities ($\sigma$). Stacking layers means stacking these compositions. That's the entire idea.

4. Vectorizing Across Multiple Examples

So far we've computed forward propagation for one training example. We need to do this for all $m$ examples efficiently.

4.1 The naive approach (loop)

# Non-vectorized — one example at a time
for i = 1 to m:
    z[1][i] = W[1] @ x[i] + b[1]
    a[1][i] = sigma(z[1][i])
    z[2][i] = W[2] @ a[1][i] + b[2]
    a[2][i] = sigma(z[2][i])

4.2 The vectorized approach

Stack all training examples as columns of the matrix $X$ (as we learned in Week 2):

$$X = \begin{bmatrix} \vert & \vert & & \vert \\ x^{(1)} & x^{(2)} & \cdots & x^{(m)} \\ \vert & \vert & & \vert \end{bmatrix}$$

Then compute the whole forward pass in one shot:

$$Z^{[1]} = W^{[1]} X + b^{[1]}, \quad A^{[1]} = \sigma(Z^{[1]})$$ $$Z^{[2]} = W^{[2]} A^{[1]} + b^{[2]}, \quad A^{[2]} = \sigma(Z^{[2]})$$

The shapes now become:

  • $X$: $(n_x, m)$ — $n_x$ features × $m$ examples
  • $Z^{[1]}, A^{[1]}$: $(n_h^{[1]}, m)$ — hidden units × examples
  • $Z^{[2]}, A^{[2]}$: $(n_y, m)$ — output units × examples
⚙️ Implementation — vectorized forward pass
def forward(X, W1, b1, W2, b2):
    Z1 = np.dot(W1, X) + b1          # shape (n_h, m)
    A1 = sigmoid(Z1)                 # element-wise
    Z2 = np.dot(W2, A1) + b2         # shape (n_y, m)
    A2 = sigmoid(Z2)
    return A2, (Z1, A1, Z2, A2)
🔴 Warning — bias broadcasting

The bias $b^{[1]}$ has shape $(n_h, 1)$, and $W^{[1]}X$ has shape $(n_h, m)$. NumPy broadcasting automatically stretches $b^{[1]}$ to $(n_h, m)$ when adding. This is exactly what we want: the same bias is added to every column (every example).

5. Why Vectorization Works (Justification)

Let's verify that the vectorized forward pass really gives the same result as the loop.

For one example $x^{(i)}$:

$$z^{[1](i)} = W^{[1]} x^{(i)} + b^{[1]}$$

Now consider the matrix product $W^{[1]} X$. Since $X$ has columns $x^{(1)}, x^{(2)}, \ldots, x^{(m)}$:

$$W^{[1]} X = W^{[1]} \begin{bmatrix} \vert & \vert & & \vert \\ x^{(1)} & x^{(2)} & \cdots & x^{(m)} \\ \vert & \vert & & \vert \end{bmatrix} = \begin{bmatrix} \vert & \vert & & \vert \\ W^{[1]}x^{(1)} & W^{[1]}x^{(2)} & \cdots & W^{[1]}x^{(m)} \\ \vert & \vert & & \vert \end{bmatrix}$$

That's exactly the pre-activations $z^{[1](1)}, z^{[1](2)}, \ldots, z^{[1](m)}$ stacked as columns. Adding $b^{[1]}$ (a vector of shape $(n_h, 1)$) broadcasts it across columns. Hence:

$$Z^{[1]} = W^{[1]} X + b^{[1]} \quad \text{where column } i \text{ is } z^{[1](i)}$$

Applying sigmoid element-wise gives $A^{[1]}$ whose column $i$ is $a^{[1](i)}$ — exactly what the loop would produce.

💡 Insight

Vectorization is possible because each example is processed independently through the network. If examples were coupled to each other, we couldn't do this in one matrix multiply. This independence is a crucial property of the standard feedforward architecture.

6. Activation Functions

🔵 Definition — Activation Function

An activation function $g(z)$ is a non-linear function applied to each neuron's pre-activation $z$. It determines the neuron's output $a = g(z)$.

So far we've used only the sigmoid. But sigmoid is not the only choice — and in practice, other functions often work much better.

6.1 Sigmoid

$$g(z) = \sigma(z) = \frac{1}{1 + e^{-z}}$$
  • Output range: $(0, 1)$.
  • Used mostly in the output layer for binary classification.
  • Problem: gradients saturate (become tiny) when $z$ is far from 0.

6.2 Tanh (hyperbolic tangent)

$$g(z) = \tanh(z) = \frac{e^{z} - e^{-z}}{e^{z} + e^{-z}}$$
  • Output range: $(-1, 1)$.
  • Almost always works better than sigmoid in hidden layers — because its output is centered at 0, making optimization easier.
  • Still saturates for large $|z|$.

6.3 ReLU (Rectified Linear Unit)

$$g(z) = \max(0, z)$$
  • Output range: $[0, \infty)$.
  • Default choice for hidden layers in modern deep learning.
  • Fast to compute, doesn't saturate for positive $z$ (gradient = 1).
  • Gradient is 0 for $z < 0$ — this can cause "dead neurons" if a unit gets stuck there.

6.4 Leaky ReLU

$$g(z) = \max(0.01\,z, z)$$
  • Same as ReLU for $z > 0$, but has a small positive slope ($0.01$) for $z < 0$.
  • Avoids the "dead neuron" problem — gradients can still flow through negative regions.

6.5 Which activation to use? A practical guide

ActivationTypical useProsCons
Sigmoid Output layer (binary classification) Output is a probability in $(0,1)$ Saturates → vanishing gradients
Tanh Hidden layers (older models) Zero-centered → better than sigmoid Still saturates
ReLU Default for hidden layers Fast; no saturation for $z>0$ "Dead neurons" for $z<0$
Leaky ReLU Hidden layers (alternative to ReLU) Avoids dead neurons Extra hyperparameter (slope)
💡 Insight — Andrew's practical recommendation

In practice: ReLU is the default for hidden layers. If you're unsure, try ReLU first. Tanh is sometimes used in specialized architectures (RNNs), and sigmoid is standard for binary classification outputs. There's no universal "best" — you need to try on your specific problem.

7. Why Non-Linear Activation Functions?

🔵 Definition — Linear activation

A linear activation is $g(z) = z$. It just passes the input through unchanged.

Why not use linear activations everywhere? Because the network would collapse to a linear model.

7.1 The proof by construction

Suppose all activations are linear: $g(z) = z$. Then:

$$a^{[1]} = W^{[1]} x + b^{[1]}$$ $$a^{[2]} = W^{[2]} a^{[1]} + b^{[2]} = W^{[2]} (W^{[1]} x + b^{[1]}) + b^{[2]}$$

Expanding:

$$a^{[2]} = (W^{[2]} W^{[1]}) x + (W^{[2]} b^{[1]} + b^{[2]})$$

This is just another linear function: $a^{[2]} = W' x + b'$ where $W' = W^{[2]} W^{[1]}$ and $b' = W^{[2]} b^{[1]} + b^{[2]}$.

⭐ Key Idea

If you stack linear layers, you get another linear layer. No matter how many layers you stack, a fully linear network is equivalent to a single linear transformation. Non-linear activations are what give depth its expressive power.

🟢 Intuition — why we want non-linearity

Real-world data relationships (image → cat, sentence → sentiment) are highly non-linear. A linear model can only carve out straight-line decision boundaries. Non-linear activations allow the network to carve out complex, curvy boundaries — the kind needed for real problems.

🔴 Warning — one common exception

In the output layer for regression problems (predicting a real number, like housing price), we often use a linear activation — because we want an unconstrained output. But the hidden layers should still be non-linear.

8. Derivatives of Activation Functions

Backpropagation needs the derivatives of the activation functions. Let's compute them.

8.1 Sigmoid derivative

$$g(z) = \sigma(z) = \frac{1}{1 + e^{-z}} \quad\Longrightarrow\quad g'(z) = g(z)(1 - g(z)) = a(1 - a)$$

Let's verify this. Write $\sigma(z) = (1 + e^{-z})^{-1}$. Using the chain rule:

$$\frac{d\sigma}{dz} = -(1 + e^{-z})^{-2} \cdot (-e^{-z}) = \frac{e^{-z}}{(1 + e^{-z})^2}$$

Now $\sigma(z) = \frac{1}{1+e^{-z}}$ and $1 - \sigma(z) = \frac{e^{-z}}{1+e^{-z}}$. Multiplying: $\sigma(z)(1-\sigma(z)) = \frac{e^{-z}}{(1+e^{-z})^2}$, which matches. ✓

🟣 Example
  • At $z = 10$: $\sigma(z) \approx 1$, so $g'(z) \approx 1 \cdot 0 = 0$. Saturated.
  • At $z = -10$: $\sigma(z) \approx 0$, so $g'(z) \approx 0 \cdot 1 = 0$. Saturated.
  • At $z = 0$: $\sigma(z) = 0.5$, so $g'(z) = 0.5 \cdot 0.5 = 0.25$. Maximum slope.

8.2 Tanh derivative

$$g(z) = \tanh(z) \quad\Longrightarrow\quad g'(z) = 1 - \tanh^2(z) = 1 - a^2$$
🟣 Example
  • At $z = 0$: $\tanh(0) = 0$, so $g'(z) = 1 - 0 = 1$. Maximum slope.
  • At large $|z|$: $\tanh(z) \to \pm 1$, so $g'(z) \to 0$. Saturated.

8.3 ReLU derivative

$$g(z) = \max(0, z) \quad\Longrightarrow\quad g'(z) = \begin{cases} 0 & \text{if } z < 0 \\ 1 & \text{if } z > 0 \end{cases}$$

Strictly speaking, ReLU is not differentiable at $z = 0$. In practice, we just define the derivative as 1 at that point (or 0 — it rarely matters since exactly 0 is a measure-zero event).

8.4 Leaky ReLU derivative

$$g(z) = \max(0.01\,z, z) \quad\Longrightarrow\quad g'(z) = \begin{cases} 0.01 & \text{if } z < 0 \\ 1 & \text{if } z > 0 \end{cases}$$
⚙️ Implementation — activation and its derivative
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def sigmoid_derivative(a):
    # a is the sigmoid output, not z
    return a * (1 - a)

def tanh_derivative(a):
    # a is the tanh output, not z
    return 1 - a**2

def relu(z):
    return np.maximum(0, z)

def relu_derivative(z):
    return (z > 0).astype(float)
💡 Insight — why sigmoid and tanh saturate

For large positive or negative $z$, the sigmoid and tanh curves flatten out. Their derivatives approach 0, which means gradients flowing backward through such a unit become tiny. In a deep network, these tiny gradients multiply together and shrink to nothing — the vanishing gradient problem. ReLU largely solves this: for $z > 0$, its derivative is exactly 1, so gradients pass through unchanged.

9. Gradient Descent for Neural Networks

Now we derive the gradient-descent update rules for a 2-layer neural network. This is the heart of backpropagation.

9.1 Parameters and cost function

Parameters: $W^{[1]}, b^{[1]}, W^{[2]}, b^{[2]}$. Cost function:

$$J(W^{[1]}, b^{[1]}, W^{[2]}, b^{[2]}) = \frac{1}{m} \sum_{i=1}^{m} L\!\left(\hat{y}^{(i)}, y^{(i)}\right)$$

where $L$ is the binary cross-entropy loss from Week 2.

9.2 The algorithm outline

Gradient descent repeats the following steps:

  1. Forward propagate to compute predictions $\hat{y}^{(i)}$ for all $i$.
  2. Backward propagate to compute gradients $dW^{[1]}, db^{[1]}, dW^{[2]}, db^{[2]}$.
  3. Update each parameter: $W := W - \alpha \cdot dW$.

9.3 The gradient equations (vectorized)

Forward propagation (recap):

$$Z^{[1]} = W^{[1]} X + b^{[1]}, \quad A^{[1]} = g^{[1]}(Z^{[1]})$$ $$Z^{[2]} = W^{[2]} A^{[1]} + b^{[2]}, \quad A^{[2]} = g^{[2]}(Z^{[2]})$$

Backward propagation:

$$dZ^{[2]} = A^{[2]} - Y$$
$$dW^{[2]} = \frac{1}{m} dZ^{[2]} A^{[1]T}$$
$$db^{[2]} = \frac{1}{m} \texttt{np.sum}(dZ^{[2]}, \text{axis}=1, \text{keepdims=True})$$
$$dZ^{[1]} = W^{[2]T} dZ^{[2]} \; * \; g^{[1]\prime}(Z^{[1]})$$
$$dW^{[1]} = \frac{1}{m} dZ^{[1]} X^T$$
$$db^{[1]} = \frac{1}{m} \texttt{np.sum}(dZ^{[1]}, \text{axis}=1, \text{keepdims=True})$$

where $*$ denotes element-wise multiplication.

🔵 Definition — Element-wise product ($*$)

The operation $A * B$ multiplies corresponding elements of two same-shaped matrices: $(A * B)_{ij} = A_{ij} \cdot B_{ij}$. In NumPy this is A * B, distinct from matrix multiplication np.dot(A, B).

9.4 Understanding each gradient equation

🟣 $dZ^{[2]} = A^{[2]} - Y$

This is the same simplification from Week 2: the gradient of the loss w.r.t. the output pre-activation is prediction minus target. It works because we paired sigmoid with cross-entropy loss.

🟣 $dW^{[2]} = \frac{1}{m} dZ^{[2]} A^{[1]T}$

The gradient w.r.t. layer-2 weights is the product of two things: the error signal at the output ($dZ^{[2]}$) and the activations that fed into it ($A^{[1]}$). The $\frac{1}{m}$ averages over examples.

🟣 $dZ^{[1]} = W^{[2]T} dZ^{[2]} * g^{[1]\prime}(Z^{[1]})$

This is the chain rule at work. The error signal flows backward from layer 2 through $W^{[2]T}$ (which transports errors from output units to hidden units), then gets multiplied by the local derivative of the hidden activation $g^{[1]\prime}(Z^{[1]})$ — the "slope gate" through the activation function.

💡 Insight — the general backward pattern

Every layer's backward pass follows the same pattern: (1) receive error signal from the next layer, (2) multiply by the local activation derivative, (3) compute weight and bias gradients using the layer's inputs. This is why deep networks can be trained layer by layer — errors propagate systematically.

⚙️ Implementation — the full training loop
for i in range(num_iterations):
    # Forward
    Z1 = np.dot(W1, X) + b1
    A1 = np.tanh(Z1)                     # or ReLU, sigmoid, ...
    Z2 = np.dot(W2, A1) + b2
    A2 = sigmoid(Z2)
    
    # Backward
    dZ2 = A2 - Y
    dW2 = (1/m) * np.dot(dZ2, A1.T)
    db2 = (1/m) * np.sum(dZ2, axis=1, keepdims=True)
    
    dZ1 = np.dot(W2.T, dZ2) * (1 - np.power(A1, 2))  # tanh derivative
    dW1 = (1/m) * np.dot(dZ1, X.T)
    db1 = (1/m) * np.sum(dZ1, axis=1, keepdims=True)
    
    # Update
    W1 -= alpha * dW1
    b1 -= alpha * db1
    W2 -= alpha * dW2
    b2 -= alpha * db2

10. Backpropagation Intuition

Backpropagation looks complicated, but it's just the chain rule organized systematically from right (output) to left (input).

🟢 Intuition — the "error signal"

Imagine $dZ^{[2]}$ as an “error message” from the output layer: it says how wrong each output is. This message flows backward through $W^{[2]T}$ to become an error signal for the hidden layer, and then gets scaled by the activation derivative $g^{[1]\prime}$. Each weight's gradient is then computed by pairing the error signal with the activation that fed into it.

⭐ Key Idea — the symmetry of forward and backward

Notice the beautiful symmetry: the forward pass goes $x \to z \to a \to \hat{y}$, and the backward pass goes $\hat{y} \to da \to dz \to dW, db$. The formulas mirror each other. This is not a coincidence — it reflects the structure of the chain rule.

11. Random Initialization

One more crucial topic: how should we initialize the weights $W$ and biases $b$ before training?

🔵 Definition — Weight initialization

Weight initialization is the procedure for setting the initial values of $W$ and $b$ before gradient descent begins.

11.1 Why not zeros?

Suppose we set all weights to 0: $W^{[1]} = \begin{bmatrix} 0 & 0 \\ 0 & 0 \end{bmatrix}$. Then every hidden unit computes the same thing:

$$a_1^{[1]} = a_2^{[1]}$$

This is because each hidden unit receives the same input, has the same (zero) weights, and adds the same (zero) bias. So all hidden units are identical.

When we backpropagate, all hidden units get the same gradient, and after updating they remain identical. They never differentiate from each other.

🔴 Warning — the symmetry problem

This is called the symmetry problem: zero-initialized hidden units never break symmetry, so having many hidden units is no better than having just one. The network can't learn rich representations.

11.2 What about biases?

Interestingly, setting biases to zero is fine. It's only the weights that must be random — because they're what break the symmetry between units.

11.3 The recommended approach

Initialize weights randomly with small values, typically scaled down by a factor like 0.01:

⚙️ Implementation — random initialization
# Initialize weights with small random values, biases with zeros
W1 = np.random.randn(n_h, n_x) * 0.01
b1 = np.zeros((n_h, 1))
W2 = np.random.randn(n_y, n_h) * 0.01
b2 = np.zeros((n_y, 1))

11.4 Why small random values?

If weights are too large, the pre-activations $z$ become large in magnitude. For sigmoid and tanh, this means the neuron is deep in the saturated region where the gradient is near 0. The network then learns very slowly.

🟢 Intuition — keeping activations in the "sweet spot"

The gradient of sigmoid/tanh is largest near $z = 0$. By using small random weights, we ensure that $z$ starts near 0, so gradients are healthy and learning proceeds quickly. As training progresses, the network adjusts weights to where they're most useful.

💡 Insight — the 0.01 is not sacred

The multiplier 0.01 is a common default, but for very deep networks, more sophisticated schemes like Xavier initialization (which scales by $1/\sqrt{n^{[l-1]}}$) or He initialization (scales by $\sqrt{2/n^{[l-1]}}$) work better. These are covered in Course 2.

12. Common Mistakes & Clarifications

🔴 Mistake 1 — Calling a 1-hidden-layer net a "1-layer NN"

A network with one hidden layer is a 2-layer NN in this course's convention. The input layer doesn't count because it just passes data through. Layer 1 = hidden, Layer 2 = output.

🔴 Mistake 2 — Confusing element-wise product with matrix multiplication

In $dZ^{[1]} = W^{[2]T} dZ^{[2]} * g^{[1]\prime}(Z^{[1]})$, the $*$ is element-wise multiplication (NumPy *), not matrix multiplication (np.dot). Mixing these up silently produces wrong shapes or wrong math.

🔴 Mistake 3 — Using linear activation in hidden layers

Stacking linear layers gives another linear layer. Hidden layers must have non-linear activations (ReLU, tanh, etc.) for the network to have any expressive power beyond a single linear model.

🔴 Mistake 4 — Initializing all weights to zero

Zero initialization makes all hidden units symmetric and prevents the network from learning diverse features. Always initialize weights randomly (small values). Biases can be zero.

🔴 Mistake 5 — Using too-large random weights

If weights are too large, sigmoid/tanh saturate and gradients vanish. Use * 0.01 (or more sophisticated schemes for deep nets) as a starting point.

🔴 Mistake 6 — Forgetting keepdims in sum

When computing $db^{[1]}$ or $db^{[2]}$ via np.sum(..., axis=1), forgetting keepdims=True produces a 1-D array instead of a column vector, causing broadcasting bugs downstream. Always specify keepdims=True.

🔴 Mistake 7 — Using sigmoid everywhere

Sigmoid is fine for the output of binary classification, but for hidden layers, tanh or ReLU usually trains faster and to a better solution. Default to ReLU unless you have a reason not to.

🔴 Mistake 8 — Confusing $g^{[1]\prime}(Z^{[1]})$ with $g^{[1]}(Z^{[1]})$

The activation is $g(z)$; its derivative is $g'(z)$. In backprop we need the derivative. In NumPy, for sigmoid you compute $a(1-a)$, not $a$ itself.

13. Weekly Summary & Review

📌 Weekly Summary

1. From logistic regression to a neural network. A 2-layer NN adds a hidden layer between input and output. Hidden units are small logistic-regression-like neurons; their outputs feed the final output neuron.

2. Notation. $a^{[0]} = x$, hidden layer 1 has $W^{[1]}, b^{[1]}$, output layer 2 has $W^{[2]}, b^{[2]}$, and $\hat{y} = a^{[2]}$. $W^{[l]}$ has shape (units in layer $l$, units in layer $l-1$).

3. Forward propagation. $z^{[1]} = W^{[1]}x + b^{[1]}$, $a^{[1]} = g^{[1]}(z^{[1]})$, $z^{[2]} = W^{[2]}a^{[1]} + b^{[2]}$, $a^{[2]} = g^{[2]}(z^{[2]})$.

4. Vectorization. Stack examples as columns of $X$. Forward pass becomes $Z^{[1]} = W^{[1]}X + b^{[1]}$, etc. The bias broadcasts across columns.

5. Activation functions. Sigmoid (output layers, binary), Tanh (hidden layers, older), ReLU (default hidden), Leaky ReLU (alternative hidden). Choice matters.

6. Why non-linearity. Stacking linear layers produces another linear layer. Non-linear activations give depth its expressive power.

7. Derivatives. $\sigma'(z) = a(1-a)$; $\tanh'(z) = 1 - a^2$; ReLU$'(z) = 0$ or $1$ depending on sign.

8. Backpropagation. Using chain rule from output to input: $dZ^{[2]} = A^{[2]} - Y$, $dW^{[2]} = \frac{1}{m}dZ^{[2]}A^{[1]T}$, $dZ^{[1]} = W^{[2]T}dZ^{[2]} * g^{[1]\prime}(Z^{[1]})$, $dW^{[1]} = \frac{1}{m}dZ^{[1]}X^T$.

9. Random initialization. Weights must be random (small) to break symmetry. Biases can be zero. Too-large weights saturate sigmoid/tanh and cause vanishing gradients.

$db^{[2]} = \frac{1}{m} \texttt{np.sum}(dZ^{[2]}, \text{axis}=1, \text{keepdims=True})$Gradient w.r.t. layer-2 bias
$dZ^{[1]} = W^{[2]T} dZ^{[2]} * g^{[1]\prime}(Z^{[1]})$Gradient propagated back to layer 1
$dW^{[1]} = \frac{1}{m} dZ^{[1]} X^T$Gradient w.r.t. layer-1 weights
$db^{[1]} = \frac{1}{m} \texttt{np.sum}(dZ^{[1]}, \text{axis}=1, \text{keepdims=True})$Gradient w.r.t. layer-1 bias
$W^{[l]} \sim \mathcal{N}(0, 0.01^2)$Small random initialization

⚠️ Common Confusions Recap

ConfusionResolution
"1-layer" vs "2-layer" NNThis course counts only the hidden and output layers. A 1-hidden-layer NN is a "2-layer NN."
Sigmoid vs tanhSigmoid outputs $(0, 1)$; tanh outputs $(-1, 1)$ and is zero-centered. Tanh usually trains faster for hidden layers.
ReLU vs Leaky ReLUReLU has 0 slope for $z < 0$ (dead neuron risk); Leaky ReLU has a small positive slope (0.01) so gradients still flow.
$g(z)$ vs $g'(z)$The activation value vs its derivative. In backprop we need the derivative.
$*$ vs np.dot$*$ is element-wise multiplication; np.dot is matrix multiplication. Both appear in backprop.
W vs b initializationW must be random (small); b can be zero. Only W needs to break symmetry.

📝 Quick Review (Click to Reveal Answers)

Why is a network with one hidden layer called a "2-layer NN"?
Because the input layer doesn't count (it just passes data through). We count the hidden layer (layer 1) and the output layer (layer 2).
What is the shape of $W^{[1]}$ for a network with 3 inputs and 4 hidden units?
$(4, 3)$ — (units in layer 1) × (units in layer 0).
Write the forward propagation equations for a 2-layer NN (single example).
$z^{[1]} = W^{[1]}x + b^{[1]}$; $a^{[1]} = g^{[1]}(z^{[1]})$; $z^{[2]} = W^{[2]}a^{[1]} + b^{[2]}$; $a^{[2]} = g^{[2]}(z^{[2]})$.
How do you vectorize forward propagation across $m$ examples?
Stack examples as columns of $X$. Then $Z^{[1]} = W^{[1]}X + b^{[1]}$, $A^{[1]} = g^{[1]}(Z^{[1]})$, $Z^{[2]} = W^{[2]}A^{[1]} + b^{[2]}$, $A^{[2]} = g^{[2]}(Z^{[2]})$. Shapes: $Z^{[1]}, A^{[1]}$ are $(n_h, m)$, $Z^{[2]}, A^{[2]}$ are $(n_y, m)$.
What is the range of the tanh function, and how does it differ from sigmoid?
Tanh outputs $(-1, 1)$; sigmoid outputs $(0, 1)$. Tanh is zero-centered, which usually makes optimization more efficient for hidden layers.
What is the formula for ReLU?
$\text{ReLU}(z) = \max(0, z)$.
Why is it bad to use a linear activation in hidden layers?
Because composing linear functions gives another linear function. A deep network with only linear activations is equivalent to a single-layer linear model — depth gives no additional expressive power. Non-linear activations are essential.
What is the derivative of sigmoid in terms of its output $a$?
$\sigma'(z) = a(1-a)$.
What is the derivative of tanh in terms of its output $a$?
$\tanh'(z) = 1 - a^2$.
Write the vectorized formula for $dZ^{[2]}$.
$dZ^{[2]} = A^{[2]} - Y$.
Write the formula for $dW^{[2]}$.
$dW^{[2]} = \frac{1}{m} dZ^{[2]} A^{[1]T}$.
Write the formula for $dZ^{[1]}$.
$dZ^{[1]} = W^{[2]T} dZ^{[2]} * g^{[1]\prime}(Z^{[1]})$, where $*$ is element-wise multiplication.
Why is the element-wise product used in $dZ^{[1]}$ instead of matrix multiplication?
Because the chain rule requires the local derivative $g^{[1]\prime}(Z^{[1]})$ to be applied element-wise to each pre-activation. Matrix multiplication is used to propagate the error back ($W^{[2]T}dZ^{[2]}$), but the activation derivative is applied element-wise.
What happens if you initialize all weights to zero?
All hidden units compute the same output and receive the same gradient, so they stay identical throughout training. The network can't learn diverse features — this is the symmetry problem.
Why must weights be initialized randomly?
To break symmetry between hidden units, so each unit can learn to detect different features.
Why small random values (e.g., ×0.01) rather than large ones?
Large weights cause sigmoid/tanh pre-activations to be far from 0, where the derivatives are tiny — leading to vanishing gradients and slow training. Small weights keep activations near the "sweet spot" where gradients are healthy.
Can biases be initialized to zero?
Yes. Biases don't cause the symmetry problem — only weights do. So $b^{[1]} = 0$ and $b^{[2]} = 0$ are standard.
Why does ReLU help avoid the vanishing gradient problem?
For $z > 0$, the ReLU derivative is exactly 1, so gradients pass through unchanged. Sigmoid and tanh saturate (derivative → 0) for large $|z|$, causing gradients to shrink as they propagate backward.
What does keepdims=True do in np.sum?
It preserves the reduced dimension as size 1, so np.sum(dZ, axis=1, keepdims=True) returns a column vector of shape (n, 1) rather than a flat array of shape (n,). This preserves the shape convention needed for broadcasting.
Sketch the backward pass for a 2-layer NN in words.
(1) Compute the output error $dZ^{[2]} = A^{[2]} - Y$. (2) Compute $dW^{[2]}, db^{[2]}$. (3) Propagate the error back through $W^{[2]T}$, multiply element-wise by $g^{[1]\prime}(Z^{[1]})$ to get $dZ^{[1]}$. (4) Compute $dW^{[1]}, db^{[1]}$. (5) Update all parameters.

🧠 Self-Test (Conceptual)

You have a 2-layer NN with 100 input features, 50 hidden units, and 1 output unit. What are the shapes of $W^{[1]}, b^{[1]}, W^{[2]}, b^{[2]}$?
$W^{[1]}$: $(50, 100)$; $b^{[1]}$: $(50, 1)$; $W^{[2]}$: $(1, 50)$; $b^{[2]}$: $(1, 1)$.
Your 2-layer NN achieves the same performance as logistic regression. What might be wrong?
Likely the hidden layer is using a linear activation. If $g^{[1]}(z) = z$, the whole network collapses to a linear model. Change the hidden activation to ReLU or tanh.
During training, the loss stops decreasing very early. What might cause this?
Several possibilities: (1) weights initialized too large → saturated activations → tiny gradients; (2) learning rate too small; (3) all weights initialized to zero → symmetry problem; (4) wrong activation derivative used in backprop.
You notice $db^{[1]}$ has shape $(50,)$ instead of $(50, 1)$. What did you likely forget?
You forgot keepdims=True in np.sum(dZ1, axis=1). Without it, NumPy drops the reduced dimension, giving a 1-D array instead of a column vector.
Why does the choice of activation function have a bigger impact in hidden layers than in output layers?
The output layer's activation is largely determined by the task: probability for binary classification (sigmoid), a real value for regression (linear). Hidden layers, however, benefit from non-linearities that avoid saturation (ReLU) and keep activations centered (tanh). The hidden activation choice affects how gradients flow through the whole network, so it has a much larger effect on training dynamics.
Someone says: "Since my network has 4 hidden units and only 3 inputs, it must be overfitting." Is this a valid conclusion?
No. Network size alone doesn't determine overfitting. What matters is the relationship between total parameter count, training set size, and regularization. A small network with 4 hidden units may underfit rather than overfit — you'd need to check train vs dev error to diagnose.
Explain in one sentence why backpropagation is efficient.
Because it computes all parameter gradients in a single backward sweep using the chain rule, reusing intermediate quantities rather than recomputing them per parameter.
