Week 4 — Face Recognition & Neural Style Transfer

Course 4 (Convolutional Neural Networks) · Deep Learning Specialization · Andrew Ng

🔵 What This Week Is About

This week has two main applications. First, face recognition — including face verification vs recognition, the one-shot learning problem, Siamese networks, and triplet loss. Second, neural style transfer — generating a new image that has the content of one image and the style of another, using a pretrained ConvNet's features. We close with 1D and 3D generalizations of convolutions (audio, medical volumes, video).

🟢 The Big Idea Connecting Everything

Both applications reuse a pretrained CNN as a fixed feature extractor. Face recognition uses the CNN's final embedding to compare two faces. Style transfer uses the CNN's intermediate activations to measure content similarity and its channel correlations to measure style similarity. In both cases we leverage knowledge learned on large datasets (ImageNet) without re-training the backbone.

1. Face Recognition — Introduction

1.1 Two different problems

Face VerificationFace Recognition
Input An image + a claimed identity (name / ID) An image + a database of \(K\) known people
Output Is this image the claimed person? (yes/no) Who is this? (ID, or "not recognized")
Also called 1:1 problem 1:K problem
Typical accuracy needed Very high (99%+ for access control) Extremely high (99.9%+) — errors are costly
🟢 Intuition — Door Lock vs Police Lineup
  • Verification is like a door that unlocks if the face matches the person who claims to live there. It answers a yes/no question.
  • Recognition is like a police officer looking at a face and asking "which of these 1000 suspects is it?" It searches a database.
🟡 Important — Why Recognition Is Harder

Verification is a binary decision on one pair of images. Recognition requires comparing the input to K stored identities and picking the best match. Its accuracy depends on the verification accuracy plus the ability to reject non-matching inputs ("none of the above").

2. The One-Shot Learning Problem

2.1 The problem

In a typical face recognition system, you might have only one photo of each employee to enroll them. You cannot train a standard softmax classifier — you'd need many images per class, and adding a new employee would require retraining.

🔵 Definition — One-Shot Learning

One-shot learning means learning to recognise a new class (a new person) from a single example. Face recognition is the canonical one-shot problem because you often have only one reference photo per person.

Figure 2.1 — One-shot learning: the system must decide whether a new face matches one of the enrolled people, having seen only a single reference image each. This is why standard softmax classification doesn't directly apply.

2.2 The fix — learn a similarity function

🔵 Definition — Similarity Function

A similarity function \(d(\text{img}_1, \text{img}_2)\) outputs a number measuring how different two images are. If \(d\) is small, the images are of the same person; if \(d\) is large, they are different people.

$$ d(\text{img}_1, \text{img}_2) \le \tau \;\Rightarrow\; \text{"same person"}, \qquad d(\text{img}_1, \text{img}_2) > \tau \;\Rightarrow\; \text{"different person"}. $$

Where \(\tau\) is a threshold chosen to trade off false accepts vs false rejects.

🟢 The Key Insight

Instead of training the network to recognise a fixed set of people, we train it to answer the generic question: "are these two images of the same person?" Then we can apply it to anyone, even people the network never saw during training — because the network learned a similarity metric, not fixed identities.

3. Siamese Network

3.1 Architecture

🔵 Definition — Siamese Network

A Siamese network is a neural network architecture where the same network (with shared weights) is applied to two different inputs, producing two encodings. The distance between those encodings tells us whether the inputs are similar.

Figure 3.1 — Siamese network. Two input images go through the same ConvNet (identical weights) to produce two 128-dimensional encodings. The distance between the encodings determines whether the faces match.

3.2 The encoding \(f(x)\)

The output of the final layer, \(f(x)\), is a vector of usually 128 numbers. This is the network's embedding of the face — a compact numerical representation capturing identity-relevant features.

$$ d(x^{(1)}, x^{(2)}) = \left\| f(x^{(1)}) - f(x^{(2)}) \right\|_2^2 $$

Where \(\|\cdot\|_2^2\) is the squared Euclidean (L2) distance between the two encodings.

3.3 The learning goal

We want to learn the parameters of the ConvNet so that:

  • If \(x^{(1)}\) and \(x^{(2)}\) are the same person → \(\|f(x^{(1)}) - f(x^{(2)})\|^2\) is small.
  • If \(x^{(1)}\) and \(x^{(2)}\) are different people → \(\|f(x^{(1)}) - f(x^{(2)})\|^2\) is large.
🟡 Important — The 128-D Embedding Choice

128 is a common choice (from the FaceNet paper). Fewer dimensions may not capture enough identity information; more dimensions increase computation. 128 is a sweet spot. The exact number is a hyperparameter.

4. Triplet Loss

How do we actually train a Siamese network? The dominant approach is triplet loss.

4.1 The three images

Each training example consists of three images:

Figure 4.1 — A triplet: an anchor (A), a positive image of the same person (P), and a negative image of a different person (N). We want \(f(A)\) close to \(f(P)\) and far from \(f(N)\).

4.2 The loss

We want:

$$ \left\| f(A) - f(P) \right\|^2 + \alpha \;\le\; \left\| f(A) - f(N) \right\|^2 $$

Equivalently:

$$ \left\| f(A) - f(P) \right\|^2 - \left\| f(A) - f(N) \right\|^2 + \alpha \;\le\; 0 $$

Where \(\alpha\) is the margin (a hyperparameter, e.g., 0.2). It forces the network to separate the positive pair from the negative pair by at least \(\alpha\).

4.3 The triplet loss formula

Triplet loss for a single triplet
$$ \mathcal{L}(A, P, N) = \max\!\left( \left\| f(A) - f(P) \right\|^2 - \left\| f(A) - f(N) \right\|^2 + \alpha, \; 0 \right) $$
Total cost over the training set
$$ J = \sum_{i=1}^{m} \mathcal{L}\!\left(A^{(i)}, P^{(i)}, N^{(i)}\right) $$
🟢 Intuition — Why the \(\max(\cdot, 0)\)?

If the inequality is already satisfied (positive pair much closer than negative pair), the expression inside \(\max\) is negative. We don't want to reward the network beyond that — so we clamp to 0. Only when the network is "violating" the margin does the loss contribute a positive gradient.

🟣 Worked Example

Suppose for a triplet:

  • \(\|f(A) - f(P)\|^2 = 0.2\)   (positive pair close — good)
  • \(\|f(A) - f(N)\|^2 = 0.5\)   (negative pair further — also good)
  • \(\alpha = 0.2\)

Then \(0.2 - 0.5 + 0.2 = -0.1 < 0\), so \(\mathcal{L} = \max(-0.1, 0) = 0\). No gradient — the triplet is satisfied.

If instead \(\|f(A) - f(N)\|^2 = 0.3\), then \(0.2 - 0.3 + 0.2 = 0.1 > 0\), so \(\mathcal{L} = 0.1\). The loss penalises the network for not separating the positive and negative pairs enough.

🟡 Important — Training Set Requirements

Training a triplet-loss network requires many images per person — usually around 1000 images per person across ~1000 people (≈1M images total). The model never learns identities directly — only a distance metric. That's why it generalises to new faces at test time.

5. Choosing Triplets — Hard Mining

5.1 Why random triplets fail

🟢 The Problem

If you pick \(A\), \(P\), \(N\) uniformly at random, the constraint \(\|f(A) - f(P)\|^2 + \alpha \le \|f(A) - f(N)\|^2\) is satisfied very easily — most random negative pairs are already far apart. The loss is almost always 0, so the network learns nothing.

5.2 Hard triplet mining

We want to focus training on hard triplets — where the anchor-positive distance is close to or larger than the anchor-negative distance. Concretely:

$$ \left\| f(A) - f(P) \right\|^2 \;\approx\; \left\| f(A) - f(N) \right\|^2 $$

These are the triplets where the constraint is barely satisfied or violated, and where the network needs to do more work.

Figure 5.1 — Easy triplets (random) yield zero loss. Hard triplets — where the positive pair is almost as far apart as the negative pair — provide useful gradients and push the network to learn better embeddings.
🔴 Warning — Don't Go Too Hard

Extremely hard triplets can be noisy or even mislabelled, leading to unstable training. A common practice is semi-hard mining — pick triplets where \(d(A,N)\) is slightly larger than \(d(A,P)\) but still "within reach." The exact strategy is a detail; the core idea is to skip easy triplets.

6. Face Verification as Binary Classification

Triplet loss is one way to train a face encoder. Another common approach is to formulate the entire problem as binary classification — output 1 if two images are the same person, 0 otherwise.

6.1 Architecture

Run the two input images through a shared Siamese encoder to get \(f(x^{(i)})\) and \(f(x^{(j)})\). Compute the element-wise absolute difference or squared difference, then pass through a small classification head:

$$ \hat{y} = \sigma\!\left( \sum_k w_k \cdot \left| f_k(x^{(i)}) - f_k(x^{(j)}) \right| + b \right) $$

Where:

  • \(f_k(\cdot)\) — the \(k\)-th component of the encoding vector.
  • \(w_k\) — learned weights of the classifier head.
  • \(b\) — bias.
  • \(\sigma\) — sigmoid, outputting probability that the pair is the same person.
Figure 6.1 — Binary classification approach. Compute the encoding difference, then feed it through a small classifier to output "same" or "different."
🟣 Worked Example — χ² Similarity

A specific and well-known variant (DeepFace, Taigman et al. 2014) uses the χ² (chi-square) similarity:

$$ \hat{y} = \sigma\!\left( \sum_k w_k \cdot \frac{(f_k(x^{(i)}) - f_k(x^{(j)}))^2}{f_k(x^{(i)}) + f_k(x^{(j)})} + b \right) $$

This weights differences by the sum of activations, giving a slightly more robust distance metric than plain squared difference.

🟡 Important — Two Equivalent Formulations

Both triplet loss and binary classification train a Siamese network. In practice:

  • Triplet loss — trains an embedding where Euclidean distance directly reflects similarity. Used by FaceNet.
  • Binary classification — trains a classifier on top of the embedding. Can be slightly more stable to train and doesn't require triplet mining.

Many modern systems use one or combine both.

7. Neural Style Transfer — Introduction

Gatys et al., 2015, "A neural algorithm of artistic style." Given a content image (e.g., a photo of a building) and a style image (e.g., Van Gogh's Starry Night), produce a new image that has the content of the first and the style of the second.

Figure 7.1 — Neural style transfer. Combine content from one image with style from another to generate a new artistic image.
🟢 Intuition — Chef Analogy

Imagine a chef (the algorithm) preparing a dish. The content image is the ingredients (a chicken, vegetables). The style image is the cuisine (Thai, Italian, French). The output is a dish made of those ingredients, prepared in that cuisine's style.

8. What Deep ConvNets Learn

Before we can define "content" and "style," we need to understand what different layers of a CNN capture. The standard way to visualise this is activation maximisation: for each unit in a layer, find the image patches that produce the strongest activation.

🔵 Definition — Activation Maximisation

For a chosen unit (neuron) in a layer, search over many images (or optimise an image) to find the input that maximally activates that unit. The patch shown reveals what that unit "detects."

Figure 8.1 — Hierarchy of features. Layer 1 detects simple edges and colour blobs. Layer 2 detects textures and simple patterns. Deeper layers detect higher-level objects (dogs, cars, people). This hierarchy emerges automatically from training.
🟡 Important — Why This Matters for Style Transfer

Style transfer exploits this hierarchy. Deeper layers capture semantic content (what objects are present), so matching them preserves the content. Shallower layers capture texture and colour, and their channel correlations encode the style.

9. Neural Style Transfer Cost Function

Style transfer is an optimisation problem: we fix a pretrained ConvNet and use gradient descent to directly optimise the pixels of the generated image \(G\).

🔵 Definition — Style Transfer Cost

The cost function for style transfer combines a content cost \(J_{\text{content}}(C, G)\) (how similar \(G\)'s content is to \(C\)) with a style cost \(J_{\text{style}}(S, G)\) (how similar \(G\)'s style is to \(S\)):

$$ J(G) = \alpha \, J_{\text{content}}(C, G) + \beta \, J_{\text{style}}(S, G) $$
  • \(\alpha\) — weight on the content cost.
  • \(\beta\) — weight on the style cost.
  • The ratio \(\alpha / \beta\) controls how much style vs content is preserved in the output.

9.1 The algorithm

  1. Initialise \(G\) randomly (e.g., a \(100 \times 100 \times 3\) image of random noise).
  2. Compute the cost \(J(G)\) using the pretrained ConvNet.
  3. Update \(G\) by gradient descent on the pixels (not on the network weights):
$$ G_{i,j,c} \leftarrow G_{i,j,c} - \eta \frac{\partial J(G)}{\partial G_{i,j,c}} $$

Where \(\eta\) is the learning rate. Note: the network weights are frozen — only the image pixels are updated.

🟢 Intuition — Sculpting the Image

Imagine starting with a random pixel-noise picture. At each step, you ask: "which pixels should I tweak so that the picture looks a bit more like my content image in that content image's style?" Repeat thousands of times, and you gradually sculpt the noise into the final artwork.

🔴 Warning — Slow but Powerful

Optimising pixels directly is much slower than training a normal network. Modern implementations train a generator network (a separate CNN) that produces the stylised image in one forward pass (Johnson et al., "Perceptual Losses"). But the original formulation — optimise the pixels — is what we learn here.

10. Content Cost Function

10.1 How to compute it

  1. Pick a hidden layer \(l\) of the pretrained network. Typically a middle layer (not too shallow, not too deep).
  2. Run the content image \(C\) through the network and record activations \(a^{[l](C)}\).
  3. Run the generated image \(G\) through the same network and record activations \(a^{[l](G)}\).
  4. Measure how different they are.
Content cost
$$ J_{\text{content}}(C, G) = \frac{1}{2} \left\| a^{[l](C)} - a^{[l](G)} \right\|^2 $$
  • \(a^{[l](C)}\) — activation of layer \(l\) on the content image \(C\). Shape: \(n_H^{[l]} \times n_W^{[l]} \times n_C^{[l]}\).
  • \(a^{[l](G)}\) — activation of the same layer on the generated image \(G\).
  • \(\|\cdot\|^2\) — squared L2 norm (sum of squared differences across all elements).
  • The \(1/2\) is a mathematical convenience (cancels with the derivative's factor of 2).
🟢 Intuition — Same Content, Same Activations

If two images have the same "content" (e.g., both show the Stanford tower), a middle layer of the network will produce similar activations for them. So minimising the difference between \(a^{[l](C)}\) and \(a^{[l](G)}\) forces \(G\) to have the same content as \(C\) as the network sees it.

🟡 Important — Which Layer \(l\)?
  • Too shallow (layer 1) — activations capture low-level details; the content cost will force \(G\) to match C pixel-for-pixel, not conceptually.
  • Too deep (final layers) — activations are dominated by class-related information; the cost becomes too permissive about spatial layout.
  • Middle layers — a good balance. In practice, layer conv4_2 in VGG‑19 is a common choice.

11. Style Cost Function (Gram Matrix)

11.1 What is "style"?

🔵 Definition — Style (in this context)

The style of an image is captured by the correlations between activations across channels in a layer of the ConvNet. If two channels tend to activate together (e.g., "vertical strokes" and "blue colour" always co-occur in Starry Night), that correlation is part of its style.

🟢 Intuition — Texture Co-occurrence

Van Gogh's paintings have a distinctive texture where certain brush strokes and colours always appear together. Channel correlations capture this: "when channel 12 (a swirl detector) is active, channel 27 (a yellow detector) is also active." Matching these correlations transfers that texture.

11.2 The style matrix (Gram matrix)

For a given layer \(l\), the style matrix (also called the Gram matrix) \(G^{[l]}\) is an \(n_C^{[l]} \times n_C^{[l]}\) matrix whose \((k, k')\) entry is the correlation between channel \(k\) and channel \(k'\):

$$ G_{kk'}^{[l]} = \sum_{i=1}^{n_H^{[l]}} \sum_{j=1}^{n_W^{[l]}} a_{ijk}^{[l]} \, a_{ijk'}^{[l]} $$
  • \(a_{ijk}^{[l]}\) — activation of layer \(l\) at spatial position \((i, j)\) in channel \(k\).
  • \(i, j\) — spatial indices (height, width).
  • \(k, k'\) — channel indices, ranging over \(1, \ldots, n_C^{[l]}\).
  • \(G_{kk'}^{[l]}\) — the unnormalised correlation between channels \(k\) and \(k'\).
🟡 Important — The Gram Matrix Captures Style

Notice: the Gram matrix sums over all spatial positions. So it measures which channels tend to co-activate, regardless of where. That is what makes it a "style" descriptor — it encodes texture and pattern information while being invariant to spatial arrangement.

11.3 The style cost

Given style image \(S\) and generated image \(G\), compute the Gram matrices \(G^{[l](S)}\) and \(G^{[l](G)}\), then:

Style cost at layer \(l\)
$$ J_{\text{style}}^{[l]}(S, G) = \frac{1}{(2 \, n_H^{[l]} \, n_W^{[l]} \, n_C^{[l]})^2} \sum_{k} \sum_{k'} \left( G_{kk'}^{[l](S)} - G_{kk'}^{[l](G)} \right)^2 $$

The denominator normalises the cost by the layer's size so that different layers contribute comparable magnitudes.

11.4 Combining multiple layers

Style is best captured by looking at several layers at once. Combine the per-layer costs with weights \(\lambda^{[l]}\):

$$ J_{\text{style}}(S, G) = \sum_{l} \lambda^{[l]} \, J_{\text{style}}^{[l]}(S, G) $$
  • \(\lambda^{[l]}\) — weight for layer \(l\)'s style contribution. Often chosen so each layer contributes proportionally.
🟣 Worked Example — Gram Matrix at a Small Scale

Suppose at some layer \(n_H = 2\), \(n_W = 2\), \(n_C = 3\). Then the activations are a \(2 \times 2 \times 3\) tensor. The Gram matrix \(G^{[l]}\) is \(3 \times 3\). Its \((1,2)\) entry:

$$ G_{12}^{[l]} = \sum_{i=1}^{2} \sum_{j=1}^{2} a_{ij1} \, a_{ij2} $$

That is, multiply the value at channel 1's pixel by channel 2's pixel at each of the 4 spatial positions, then sum. The result is high if channels 1 and 2 tend to be active together.

🔴 Warning — Gram Matrix Is Not the Only Style Descriptor

The Gram matrix is a first-order approximation of style. Modern methods use more sophisticated statistics (e.g., mean + variance via instance normalisation, or learned style embeddings). But the Gram-matrix approach is the classic, and it's what the specialization teaches.

12. Putting It Together

Full neural style transfer cost
$$ J(G) = \alpha \underbrace{\frac{1}{2} \left\| a^{[l](C)} - a^{[l](G)} \right\|^2}_{J_{\text{content}}} + \beta \underbrace{\sum_{l'} \lambda^{[l']} \, J_{\text{style}}^{[l']}(S, G)}_{J_{\text{style}}} $$

12.1 The full algorithm

  1. Load a pretrained ConvNet (e.g., VGG‑19) with frozen weights.
  2. Choose a content layer \(l_{\text{content}}\) (typically middle) and a set of style layers \(\{l_{\text{style}}\}\) (typically several layers across depths).
  3. Precompute \(a^{[l_{\text{content}}](C)}\) and \(G^{[l_{\text{style}}](S)}\) once — they don't change during optimisation.
  4. Initialise \(G\) randomly.
  5. Repeat many times:
    1. Forward pass \(G\) through the network.
    2. Compute \(J(G) = \alpha J_{\text{content}} + \beta J_{\text{style}}\).
    3. Backpropagate to find \(\partial J / \partial G\) (the gradient w.r.t. the pixels of \(G\)).
    4. Update: \(G \leftarrow G - \eta \cdot \partial J / \partial G\).
  6. Return the final \(G\).
🟡 Important — The Role of \(\alpha\) and \(\beta\)
  • Larger \(\alpha\) (relative to \(\beta\)) → the output looks more like the content image (less stylistic).
  • Larger \(\beta\) → the output looks more like the style (content is more obscured).
  • Typical ratios place more weight on style (\(\beta > \alpha\)) so that the artistic texture dominates.

13. 1D Convolutions

The convolution operation generalises to 1D data, which is common in signal processing.

Figure 13.1 — 2D convolutions slide a 2D filter over an image. 1D convolutions slide a 1D filter over a 1D signal (audio waveform, ECG, sensor data).
1D convolution
$$ y_i = \sum_{k=0}^{f-1} x_{i+k} \cdot w_k + b $$
  • \(x\) — 1D input signal (e.g., audio samples).
  • \(w\) — 1D filter of length \(f\).
  • \(y_i\) — output at position \(i\).
🟡 Important — Applications of 1D Convolutions
  • Audio / speech recognition — raw waveform or spectrogram along time.
  • ECG / EEG analysis — medical time-series signals.
  • Natural language processing — 1D conv over word embeddings (before transformers dominated).
  • Sensor data — accelerometer, gyroscope streams.

14. 3D Convolutions

Some data has three spatial dimensions (volumes). The convolution operation extends naturally.

Figure 14.1 — 3D convolution. A 3D filter slides across a 3D input volume, producing a 3D output. Used in medical imaging (CT/MRI scans), video understanding, and 3D shape analysis.
3D convolution output size
$$ n_H^{[l]} = \left\lfloor \frac{n_H^{[l-1]} + 2p - f}{s} \right\rfloor + 1 $$ $$ n_W^{[l]} = \left\lfloor \frac{n_W^{[l-1]} + 2p - f}{s} \right\rfloor + 1, \qquad n_D^{[l]} = \left\lfloor \frac{n_D^{[l-1]} + 2p - f}{s} \right\rfloor + 1 $$
  • \(n_H, n_W, n_D\) — height, width, and depth of the volume.
  • Output has the same number of channels as the number of 3D filters used.
🟡 Important — The Same Design Principles Apply

All of the ideas from 2D CNNs — padding, stride, pooling, batch norm, residual connections — carry over to 1D and 3D versions. The convolution operation is dimension-agnostic.

🔴 Warning — 3D Convs Are Expensive

3D convolutions have a parameter count that scales with \(f^3\) (cubed) instead of \(f^2\). This makes them much more memory- and compute-intensive. Many medical imaging models use 2D slices or factorised (2D + 1D) convolutions instead.

15. Weekly Summary

  • Face verification — 1:1 decision. Input image + claimed ID → yes/no.
  • Face recognition — 1:K decision. Input image + database → identity or "not recognized".
  • One-shot learning — learning a new identity from a single example. Solved by learning a similarity function rather than a classifier.
  • Similarity function \(d(\text{img}_1, \text{img}_2)\) — small if same person, large otherwise.
  • Siamese network — same ConvNet applied to two images; compare their \(128\)-dim encodings.
  • Triplet loss — given (Anchor, Positive, Negative), learn so that \(d(A,P) + \alpha \le d(A,N)\).
  • Hard triplet mining — train only on triplets where the margin is nearly violated.
  • Binary classification — alternative: feed \(|f(x^{(i)}) - f(x^{(j)})|\) into a small classifier to output "same/different."
  • Neural style transfer — optimise image pixels to combine content of one image with style of another.
  • Content cost — match activations at a mid-level layer: \(J_{\text{content}} = \frac{1}{2} \|a^{[l](C)} - a^{[l](G)}\|^2\).
  • Style cost — match Gram matrices (channel correlations) at several layers.
  • Total cost \(J(G) = \alpha J_{\text{content}} + \beta J_{\text{style}}\).
  • 1D and 3D convolutions — same ideas generalise to signals, medical volumes, video.

17. Common Confusions

Often confusedCorrect distinction
Face verification vs face recognition Verification = 1:1 yes/no. Recognition = 1:K, pick from database.
One-shot learning vs traditional classification Traditional classification needs many examples per class and retrains for new classes. One-shot learns a similarity function usable on unseen classes.
Siamese network vs standard CNN Siamese uses the same weights on two inputs. Standard CNN has one input.
Triplet loss vs binary classification Triplet loss directly trains the embedding distance. Binary classification trains a head on top of the embedding to output same/different. Both work.
Margin \(\alpha\) vs learning rate \(\alpha\) is a fixed hyperparameter (triplet loss margin). Learning rate controls gradient step size. Totally different.
Content cost vs style cost Content cost matches activations at a mid-layer. Style cost matches Gram matrices (channel correlations) across multiple layers.
Gram matrix vs activation Activations are the raw \(n_H \times n_W \times n_C\) tensor. Gram matrix is \(n_C \times n_C\), summarising spatial correlations between channels.
Freezing network vs optimising pixels Style transfer keeps network weights frozen and optimises the pixels of the generated image. Different from normal training.
2D vs 3D convolution Same principle, extra dimension. 3D convolutions are for volumes (CT scans, video, etc.). Parameter count scales as \(f^3\), not \(f^2\).

18. Review Questions

Q1. What is the difference between face verification and face recognition?
Face verification: given an image + claimed identity, output yes/no (1:1). Face recognition: given an image + a database of K people, output the matching identity or "not recognized" (1:K). Recognition is essentially verification applied K times.
Q2. Why can't we just train a softmax classifier for face recognition?
Two reasons: (1) you often have only one photo per person (one-shot learning), so no class has enough training data; (2) adding a new person requires retraining the softmax layer. Instead, learn a similarity function that generalises to unseen identities.
Q3. What is a Siamese network?
A network architecture where the same ConvNet (shared weights) processes two input images, producing two encoding vectors \(f(x^{(1)}), f(x^{(2)})\). The distance between these encodings determines similarity.
Q4. Write the triplet loss equation and explain each term.
$$\mathcal{L}(A,P,N) = \max\!\left(\|f(A) - f(P)\|^2 - \|f(A) - f(N)\|^2 + \alpha, \; 0\right)$$ \(A, P, N\) = anchor, positive, negative images. \(f(\cdot)\) = ConvNet encoding. \(\alpha\) = margin. The loss is 0 if the positive pair is closer by at least \(\alpha\), otherwise the difference.
Q5. What is the margin \(\alpha\) and why is it needed?
The margin forces the network to keep a buffer between same-person distances and different-person distances. Without it, the network could trivially satisfy the constraint by making all distances nearly equal. \(\alpha\) ensures positive pairs are closer by at least that gap.
Q6. What is hard triplet mining and why is it needed?
Random triplets usually satisfy the constraint trivially — the loss is zero and the network doesn't learn. Hard mining selects triplets where \(d(A,P) \approx d(A,N)\), i.e., where the network is close to violating the margin. These produce useful gradients.
Q7. Describe the binary classification approach to face verification.
Take the element-wise absolute (or squared) difference between two encodings \(|f(x^{(i)}) - f(x^{(j)})|\), pass it through a small classifier (FC + sigmoid), and output the probability that they are the same person. Train with cross-entropy loss.
Q8. What is neural style transfer?
It generates a new image \(G\) that has the content of image \(C\) and the style of image \(S\). It works by optimising the pixels of \(G\) to minimise a combined cost \(J(G) = \alpha J_{\text{content}} + \beta J_{\text{style}}\) using a pretrained CNN's features.
Q9. What does activation maximisation reveal about a CNN?
It shows what each unit "detects." Layer 1 units respond to edges and colours; layer 2 units to textures; deeper layers to object parts and full objects. It confirms the hierarchical feature learning of CNNs.
Q10. Write the content cost formula and explain the choice of layer.
$$J_{\text{content}}(C, G) = \frac{1}{2} \|a^{[l](C)} - a^{[l](G)}\|^2$$ We pick a middle layer \(l\). Shallow layers make content match too pixel-level; deep layers make it too permissive about layout. A middle layer captures "what's in the image" without being overly strict.
Q11. What is a Gram matrix and why does it capture style?
The Gram matrix \(G_{kk'}^{[l]} = \sum_{i,j} a_{ijk}^{[l]} a_{ijk'}^{[l]}\) measures correlation between channels \(k\) and \(k'\) across all spatial positions. Because it sums over spatial positions, it captures which channels co-activate, regardless of where. Style is exactly this "texture co-occurrence" — which patterns go together.
Q12. What is the full style transfer cost function?
$$J(G) = \alpha J_{\text{content}}(C, G) + \beta J_{\text{style}}(S, G)$$ where \(J_{\text{style}}(S, G) = \sum_l \lambda^{[l]} J_{\text{style}}^{[l]}(S, G)\) sums the per-layer style costs.
Q13. How is \(G\) initialised in style transfer, and what do we optimise?
\(G\) is initialised randomly (e.g., random noise of the desired size). We optimise the pixels of \(G\) via gradient descent. The pretrained network's weights are frozen — only the image is updated.
Q14. What roles do \(\alpha\) and \(\beta\) play in style transfer?
They trade off content preservation vs style strength. Larger \(\alpha\) → output looks more like the content. Larger \(\beta\) → output looks more like the style. Typical practice uses \(\beta > \alpha\) so the artistic texture dominates.
Q15. What is a 1D convolution and where is it used?
A 1D convolution slides a 1D filter over a 1D signal. Used for audio waveforms, ECG/EEG signals, natural language sequences, and sensor time-series. The mechanics are identical to 2D convolutions, just in one dimension.
Q16. What is a 3D convolution and where is it used?
A 3D convolution slides a 3D filter over a 3D volume. Used for medical imaging (CT, MRI), 3D object recognition, and video (where time is the third dimension). Parameter count scales as \(f^3\), making it more expensive than 2D.
Q17. Suppose an implementation of style transfer gives ugly results where the content is barely visible. What would you adjust?
Increase \(\alpha\) (content weight) relative to \(\beta\). This strengthens the content-preservation constraint, making the output more like the original photo, at the cost of less stylistic texture.
Q18. Why is hard triplet mining unstable if taken too far?
Extremely hard triplets are often near-mislabelled or pathological — e.g., two different photos of the same person look very different due to pose or lighting, or two different people look similar. Training on only these leads to noisy gradients. Semi-hard mining is the usual compromise.
Q19. Can face recognition generalise to new employees not seen during training? Why?
Yes — because the network learns a similarity function, not identities. When you enroll a new employee, you simply compute their encoding \(f(x)\) and store it. At test time, compare the new input's encoding to the stored one. No retraining needed.
Q20. Explain in one paragraph the connection between face recognition and style transfer in this week.
Both reuse a pretrained CNN as a fixed feature extractor. Face recognition uses the network's final embedding — a 128-d vector encoding identity — to compare two faces. Style transfer uses the network's intermediate activations to measure content similarity, and the Gram matrix (channel correlations) to measure style similarity. In both cases, knowledge learned on a large dataset (ImageNet) is transferred to a new task without retraining the backbone.

19. Self‑Test

Easy

1. Is face verification a 1:1 or 1:K problem?
1:1 — one image vs one claimed identity, output yes/no.
2. What is the output of the Siamese encoder typically called?
An encoding or embedding \(f(x)\) (typically 128-dimensional).
3. What does the Gram matrix measure?
Correlation between different channels' activations, summed over all spatial positions.
4. In style transfer, which set of parameters gets updated?
The pixels of the generated image \(G\). The network weights are frozen.
5. What is a 1D convolution used for?
Processing 1D signals — audio, ECG, EEG, time-series, etc.

Medium

6. Why is one-shot learning challenging, and what is the workaround?
Standard classifiers need many examples per class and must be retrained when new classes appear. The workaround is to learn a similarity function \(d(x^{(1)}, x^{(2)})\) that compares two images, enabling generalisation to unseen identities without retraining.
7. Why do we pick a middle layer for the content cost?
Shallow layers force the generated image to match pixel-level details of the content (too strict). Deep layers are dominated by class information (too permissive). Middle layers balance these — they capture "what's in the image" without imposing pixel-level similarity.
8. If \(\alpha = 1\) and \(\beta = 100\) in style transfer, what will the output look like?
Very stylistic — the style cost dominates, so the texture of the style image is strong. The content will still be recognisable but strongly stylised.
9. Can you apply neural style transfer to audio signals? Why or why not?
In principle, yes. The key ingredients — a pretrained network that extracts features, a content cost based on activations, and a style cost based on channel correlations — carry over to 1D signals. In practice, audio style transfer is a real research area (e.g., timbre transfer).
10. Why is binary classification for face verification sometimes preferred over triplet loss?
Binary classification avoids the triplet mining step and can be more stable to train. Triplet loss requires carefully curated hard triplets to be effective.
11. What does the \((2 n_H n_W n_C)^2\) denominator in the style cost do?
It normalises the cost so that different layers contribute comparable magnitudes. Without normalisation, layers with more activations would dominate the total cost.

Hard

12. Derive why the triplet loss can produce a zero gradient when random triplets are used.
For random triplets, images A and N are usually very different (large \(d(A,N)\)), while A and P are similar (small \(d(A,P)\)). So \(d(A,P) - d(A,N) + \alpha < 0\). Since \(\max(\cdot, 0) = 0\), the gradient is zero. The network gets no signal to improve.
13. If you have 1000 employees, how many pairs would a binary classifier need to compare at test time? How does this scale?
Each new input is compared against each enrolled employee: 1000 comparisons. This scales linearly in the number of enrolled people. Modern systems use efficient nearest-neighbour search (e.g., vector databases) to make this fast.
14. Why does the triplet loss not directly learn identities? What is the advantage?
The triplet loss only constrains relative distances between images, never asking "which person is this?". The advantage: the learned embedding space generalises to unseen people — you can recognise anyone by comparing to a stored encoding, without retraining.
15. In style transfer, why does optimising pixels produce a good image while random noise produces garbage?
The optimisation is driven by gradients of \(J(G)\) w.r.t. each pixel. Random noise has no content or style structure. The gradient tells each pixel how to change to make the network's activations (and Gram matrices) more similar to the target. Over thousands of iterations, the noise is gradually shaped into an image that satisfies both content and style objectives.
16. The Gram matrix is invariant to spatial rearrangements. Is that good or bad for style transfer?
Mostly good — style is about texture and colour patterns, not where things are. Spatial invariance means the style can be applied globally. But it's why style transfer doesn't respect spatial structure perfectly; a swirl at the top of the style image might end up at the bottom of the generated image. Modern methods add spatial controls.
17. If a face verification system has 99.9% accuracy per pair, is it good enough for a 1:1000 recognition system?
Not necessarily. With K=1000 comparisons, even a tiny per-pair error can produce meaningful mistakes at the system level. The probabilities compound. This is why recognition systems require much higher per-pair accuracy than simple verification.
18. Why do we precompute \(a^{[l](C)}\) and \(G^{[l](S)}\) before optimising \(G\)?
They don't change during optimisation (the content and style images are fixed). Precomputing them once saves a forward pass on those images at every iteration — the only forward pass needed per iteration is on the current \(G\).
19. A 3D convolution with a \(5\times 5\times 5\) filter has how many parameters per filter (single channel)? Compare to a \(5\times 5\) 2D filter.
3D: \(5 \cdot 5 \cdot 5 = 125\) parameters (plus 1 bias). 2D: \(5 \cdot 5 = 25\) parameters. So 3D is 5× more expensive per filter. For \(n_C\) input channels, the 3D filter has \(5 \cdot 5 \cdot 5 \cdot n_C\) parameters.
20. If you want to deploy a face verification system for 10,000 employees on mobile, what are the key design decisions?
(1) Use a mobile-friendly backbone (e.g., MobileNet) as the Siamese encoder. (2) Store one 128-d encoding per employee (~1.3MB total) in a fast vector-indexed database. (3) For each new input, compute its encoding once and do nearest-neighbour search. (4) Choose the similarity threshold based on the desired false-accept/false-reject trade-off. (5) Consider on-device vs server-side: on-device is privacy-preserving but lower accuracy; server-side is more powerful but requires sending the input image over the network.
