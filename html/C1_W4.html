1. What is a Deep Neural Network?

🔵 Definition — Deep Neural Network

A deep neural network is a neural network with many layers — typically more than one hidden layer. The word "deep" simply refers to the number of layers in the network.

The progression from logistic regression to a deep network can be visualized as a spectrum of increasing depth:

🟢 Intuition — why "deep"?

The word "deep" is a depth of layers, not a metaphor for intellectual depth. Deep networks are able to represent increasingly abstract and complex features by composing simpler features across many layers. We'll see in §6–§7 why this matters.

⭐ Key Idea — the L-layer convention

A network with $L$ layers has layers $1, 2, \ldots, L$ where layer $L$ is the output layer. The input is sometimes called layer 0 ($a^{[0]} = x$). If the network has 1 hidden layer, then $L = 2$. If it has 5 hidden layers, then $L = 6$.

2. Deep Neural Network Notation

Let's formalize the notation for an L-layer neural network. This generalizes everything from Weeks 2 and 3.

2.1 The notation table

SymbolMeaningExample (for the 5-5-3-1 network in the slide)
$L$Total number of layers in the network$L = 4$
$n^{[l]}$Number of units (neurons) in layer $l$$n^{[1]} = 5$, $n^{[2]} = 5$, $n^{[3]} = 3$, $n^{[4]} = 1$
$n^{[0]}$Number of input features (same as $n_x$)$n^{[0]} = n_x = 3$
$a^{[l]}$Activation vector of layer $l$ (its outputs)$a^{[1]} \in \mathbb{R}^5$, $a^{[2]} \in \mathbb{R}^5$, $\ldots$
$W^{[l]}$Weight matrix of layer $l$$W^{[1]}$ shape $(5, 3)$, $W^{[2]}$ shape $(5, 5)$, …
$b^{[l]}$Bias vector of layer $l$$b^{[1]} \in \mathbb{R}^5$, $b^{[2]} \in \mathbb{R}^5$, …
$g^{[l]}$Activation function of layer $l$Often ReLU for hidden, sigmoid for output
$a^{[0]}$The input, also written $X$$a^{[0]} = X$
$a^{[L]}$The final output, also written $\hat{y}$$a^{[L]} = \hat{y}$
💡 Insight — the shape rule for $W^{[l]}$

In any layer, $W^{[l]}$ has shape $(n^{[l]}, n^{[l-1]})$: rows = units in the current layer, columns = units in the previous layer. This is the general rule that generalizes from Weeks 2 and 3.

⭐ Key Idea — how activations are computed

Every layer computes the same pair of equations:

$$z^{[l]} = W^{[l]} a^{[l-1]} + b^{[l]}, \quad a^{[l]} = g^{[l]}(z^{[l]})$$

This is the fundamental repeated block of every neural network, no matter how deep.

3. Forward Propagation in a Deep Network

Forward propagation means computing the output of the network from the input by passing data forward through the layers.

3.1 The algorithm for a single example

Given input $x = a^{[0]}$, for each layer $l = 1, 2, \ldots, L$, compute:

$$z^{[l]} = W^{[l]} a^{[l-1]} + b^{[l]}$$ $$a^{[l]} = g^{[l]}(z^{[l]})$$

The final activation $a^{[L]}$ is the prediction $\hat{y}$.

🟣 Worked example — a 3-layer network

Suppose $L = 3$ (two hidden layers + output). Forward propagation:

$$z^{[1]} = W^{[1]}x + b^{[1]}, \quad a^{[1]} = g^{[1]}(z^{[1]})$$ $$z^{[2]} = W^{[2]}a^{[1]} + b^{[2]}, \quad a^{[2]} = g^{[2]}(z^{[2]})$$ $$z^{[3]} = W^{[3]}a^{[2]} + b^{[3]}, \quad a^{[3]} = g^{[3]}(z^{[3]}) = \hat{y}$$

Each layer takes the output of the previous layer as its input. The activation function $g^{[l]}$ can differ per layer — e.g., ReLU for hidden layers and sigmoid for the output layer in binary classification.

3.2 The general recurrence (vectorized over examples)

With all $m$ training examples stacked as columns of $X = A^{[0]}$:

$$Z^{[l]} = W^{[l]} A^{[l-1]} + b^{[l]}$$ $$A^{[l]} = g^{[l]}(Z^{[l]})$$

for $l = 1, 2, \ldots, L$, where $A^{[L]} = \hat{Y}$.

⚙️ Implementation — deep forward propagation
def forward_propagation(X, params):
    """X shape (n_x, m); params is a dict with W1, b1, W2, b2, ..."""
    L = len(params) // 2
    caches = []
    A = X                                  # A⁽⁰⁾ = X
    for l in range(1, L + 1):
        A_prev = A
        W = params[f"W{l}"]
        b = params[f"b{l}"]
        Z = np.dot(W, A_prev) + b          # Z⁽ˡ⁾
        if l < L:
            A = relu(Z)                    # hidden layers → ReLU
        else:
            A = sigmoid(Z)                 # output layer → sigmoid
        caches.append((A_prev, W, b, Z))   # save for backprop
    return A, caches

Notice: the same two-line operation is repeated $L$ times. This is the essence of "deep" — a repeated block applied many times.

💡 Insight — depth as repetition

Forward propagation in a deep network is nothing more than applying the same 2-line transformation $L$ times. Once you understand one layer, you understand all of them.

4. Getting Matrix Dimensions Right

Shape bugs are the #1 source of frustration in deep learning code. Getting dimensions right is essential.

4.1 Layer-by-layer shape rules

For a single example $x \in \mathbb{R}^{n^{[0]}}$:

QuantityShape (single example)Shape ($m$ examples)
$a^{[l]}$$(n^{[l]}, 1)$$(n^{[l]}, m)$ — call it $A^{[l]}$
$z^{[l]}$$(n^{[l]}, 1)$$(n^{[l]}, m)$ — call it $Z^{[l]}$
$W^{[l]}$$(n^{[l]}, n^{[l-1]})$$(n^{[l]}, n^{[l-1]})$ — same
$b^{[l]}$$(n^{[l]}, 1)$$(n^{[l]}, 1)$ — same
$dW^{[l]}$$(n^{[l]}, n^{[l-1]})$$(n^{[l]}, n^{[l-1]})$
$db^{[l]}$$(n^{[l]}, 1)$$(n^{[l]}, 1)$
⭐ Key Idea — the two universal rules
  1. W rule: $W^{[l]}$ always has shape $(n^{[l]}, n^{[l-1]})$.
  2. b rule: $b^{[l]}$ always has shape $(n^{[l]}, 1)$ — a column vector, one bias per unit.

These two rules determine everything else.

4.2 Verifying the forward pass shapes

For the vectorized forward pass $Z^{[l]} = W^{[l]} A^{[l-1]} + b^{[l]}$:

$$\underbrace{(n^{[l]}, m)}_{Z^{[l]}} = \underbrace{(n^{[l]}, n^{[l-1]})}_{W^{[l]}} \cdot \underbrace{(n^{[l-1]}, m)}_{A^{[l-1]}} + \underbrace{(n^{[l]}, 1)}_{b^{[l]}}$$

Check:

  • $W^{[l]} A^{[l-1]}$: $(n^{[l]}, n^{[l-1]}) \cdot (n^{[l-1]}, m) = (n^{[l]}, m)$ ✓
  • Adding $b^{[l]}$ (shape $(n^{[l]}, 1)$): broadcast to $(n^{[l]}, m)$ ✓
  • Result $Z^{[l]}$: shape $(n^{[l]}, m)$ ✓

4.3 A concrete numeric example

Consider a 2-layer network with $n^{[0]} = 2$ inputs, $n^{[1]} = 3$ hidden units, $n^{[2]} = 1$ output, and $m = 5$ examples:

QuantityShape
$X = A^{[0]}$$(2, 5)$
$W^{[1]}$$(3, 2)$
$b^{[1]}$$(3, 1)$
$Z^{[1]} = W^{[1]}X + b^{[1]}$$(3, 5)$
$A^{[1]}$$(3, 5)$
$W^{[2]}$$(1, 3)$
$b^{[2]}$$(1, 1)$
$Z^{[2]} = W^{[2]}A^{[1]} + b^{[2]}$$(1, 5)$
$A^{[2]} = \hat{Y}$$(1, 5)$
🔴 Warning — debugging shapes

When writing deep-learning code, always print or assert shapes as you build up the forward pass. Use assert Z.shape == (n_l, m) after computing each layer. Shape bugs often don't throw exceptions — they silently produce wrong numbers.

5. Vectorized Implementation

We've already seen how to vectorize across examples in Week 3. Here we generalize it to $L$ layers.

The full vectorized forward pass for the deep network is:

$$Z^{[l]} = W^{[l]} A^{[l-1]} + b^{[l]}, \quad A^{[l]} = g^{[l]}(Z^{[l]}), \quad l = 1, \ldots, L$$

With all $m$ examples handled simultaneously as columns of $A^{[l]}$ and $Z^{[l]}$.

💡 Insight — why vectorization scales

Because each example is processed independently through the network, all $m$ examples can be processed with one matrix multiplication per layer. On a GPU, that's a single parallel operation over $m$ examples. Without vectorization, you'd need $m$ sequential passes through the network — orders of magnitude slower.

🟣 Example — 3-layer vectorized forward
# X shape (n_x, m)
Z1 = np.dot(W1, X)   + b1    # (n1, m)
A1 = relu(Z1)                # (n1, m)
Z2 = np.dot(W2, A1)  + b2    # (n2, m)
A2 = relu(Z2)                # (n2, m)
Z3 = np.dot(W3, A2)  + b3    # (n3, m)
A3 = sigmoid(Z3)             # (n3, m) — final output Ŷ

No loop over examples. Every layer processes all $m$ examples at once.

6. Why Deep Representations?

Why go deep instead of just wide? Why not have one very wide hidden layer?

The answer involves composition of features — each layer builds on the features learned by the previous layer.

6.1 The face-recognition intuition

Andrew uses a classic example from computer vision: a deep network trained to recognize faces learns a hierarchy of increasingly abstract features.

🟢 Intuition — building abstraction hierarchically

Simple features (edges) → medium features (eyes, noses) → complex features (faces) → prediction. Each layer composes the layer below it. This is feature composition and it's the core reason depth helps.

6.2 The same idea in other domains

This hierarchical composition appears everywhere in deep learning:

  • Audio: low-level audio waveforms → phonemes → words → sentences → meaning.
  • Text (NLP): characters → words → phrases → sentences → document sentiment.
  • Images: edges → textures → object parts → objects → scenes.
⭐ Key Idea — early layers are simpler

In a deep network, the early layers learn simple, general features (edges, tones, common patterns). The later layers learn complex, task-specific features (faces, sentences, objects). This is why deep representations are so powerful.

7. Circuit Theory and Deep Learning

There's a theoretical result that explains why depth is fundamentally more powerful than width.

🔵 Definition — Circuit Theory Result

Informally: There are functions that a "small" $L$-layer deep neural network can compute, but that a shallower network would need exponentially more hidden units to compute.

7.1 XOR example

Consider computing the XOR (exclusive-or) of many inputs:

$$y = x_1 \oplus x_2 \oplus x_3 \oplus \cdots \oplus x_n$$

XOR returns 1 if an odd number of inputs is 1, and 0 otherwise.

How does depth help here?

🟢 Intuition — why depth gives exponential savings

Each layer can reuse the outputs of the layer below. In the XOR example, the tree structure means each output is computed from two sub-results, which are computed from two sub-sub-results, etc. This "divide and conquer" strategy is exponential in its savings.

A shallow network, by contrast, must compute every combination "from scratch" in a single layer, requiring an exponential number of units.

⭐ Key Idea — depth matters, but practically too

While this circuit-theory result is theoretical, it matches practice: deep networks often outperform shallow ones on complex tasks, especially in vision, speech, and language, even with similar numbers of parameters. This is one reason the field moved toward deeper and deeper networks.

8. Building Blocks: Forward & Backward Functions

Deep networks are built out of repeated blocks. Each layer has a forward function (computing activations) and a backward function (computing gradients).

🔵 Definition — Cache

A cache is the set of intermediate values saved during the forward pass so the backward pass can reuse them. For layer $l$, we cache $z^{[l]}$ (and possibly $a^{[l-1]}$, $W^{[l]}$, $b^{[l]}$). Without caching, we'd have to recompute these values during backprop — much slower.

💡 Insight — the modular pattern

Every layer has the same interface: forward takes $a^{[l-1]}$ and produces $a^{[l]}$; backward takes $da^{[l]}$ and produces $da^{[l-1]}$. This modularity is why deep networks can be implemented with a simple loop over layers — exactly the same operation, repeated $L$ times.

9. Forward and Backward Propagation for Layer l

9.1 Forward function for layer l

Input: $a^{[l-1]}$ (activations from previous layer). Output: $a^{[l]}$ (and a cache of $z^{[l]}$, $W^{[l]}$, $b^{[l]}$).

$$z^{[l]} = W^{[l]} a^{[l-1]} + b^{[l]}$$ $$a^{[l]} = g^{[l]}(z^{[l]})$$

9.2 Backward function for layer l

Input: $da^{[l]}$ (gradient from the next layer). Output: $da^{[l-1]}$, $dW^{[l]}$, $db^{[l]}$.

$$dz^{[l]} = da^{[l]} * g^{[l]\prime}(z^{[l]})$$
$$dW^{[l]} = dz^{[l]} \cdot a^{[l-1]T}$$
$$db^{[l]} = dz^{[l]}$$
$$da^{[l-1]} = W^{[l]T} \cdot dz^{[l]}$$

Where $*$ denotes element-wise multiplication, and $\cdot$ denotes matrix multiplication.

🟣 Explaining each equation
  • $dz^{[l]} = da^{[l]} * g^{[l]\prime}(z^{[l]})$: the chain rule. The gradient from above ($da^{[l]}$) is scaled by the local derivative of the activation function. The $*$ is element-wise because each unit has its own activation slope.
  • $dW^{[l]} = dz^{[l]} \cdot a^{[l-1]T}$: how much each weight contributed to the error. It's the outer product of the error at layer $l$ and the input activations from layer $l-1$.
  • $db^{[l]} = dz^{[l]}$: the bias gradient is just the error at layer $l$ (broadcast/averaged over examples in the vectorized case).
  • $da^{[l-1]} = W^{[l]T} \cdot dz^{[l]}$: the error is propagated back through the transpose of the weight matrix.
💡 Insight — the transpose is the key to backward flow

Forward: $z^{[l]} = W^{[l]}a^{[l-1]}$ (matrix times vector). Backward: $da^{[l-1]} = W^{[l]T}dz^{[l]}$ (transpose matrix times vector). The transposition is what allows error to "flow backward" through the same weights.

9.3 Vectorized backward functions

With $m$ examples, using capital letters for the vectorized versions:

$$dZ^{[l]} = dA^{[l]} * g^{[l]\prime}(Z^{[l]})$$ $$dW^{[l]} = \frac{1}{m} dZ^{[l]} A^{[l-1]T}$$ $$db^{[l]} = \frac{1}{m} \texttt{np.sum}(dZ^{[l]}, \text{axis}=1, \text{keepdims=True})$$ $$dA^{[l-1]} = W^{[l]T} dZ^{[l]}$$
⚙️ Implementation — one layer's backward pass
def linear_activation_backward(dA, cache, activation):
    A_prev, W, b, Z = cache
    m = A_prev.shape[1]
    
    if activation == "relu":
        dZ = dA * relu_derivative(Z)
    elif activation == "sigmoid":
        A = sigmoid(Z)
        dZ = dA * (A * (1 - A))
    
    dW = (1/m) * np.dot(dZ, A_prev.T)
    db = (1/m) * np.sum(dZ, axis=1, keepdims=True)
    dA_prev = np.dot(W.T, dZ)
    
    return dA_prev, dW, db

10. Full Forward and Backward Summary

Putting it all together for an $L$-layer network.

10.1 Forward propagation (vectorized)

$$A^{[0]} = X$$ $$Z^{[1]} = W^{[1]} A^{[0]} + b^{[1]}, \quad A^{[1]} = g^{[1]}(Z^{[1]})$$ $$Z^{[2]} = W^{[2]} A^{[1]} + b^{[2]}, \quad A^{[2]} = g^{[2]}(Z^{[2]})$$ $$\vdots$$ $$Z^{[L]} = W^{[L]} A^{[L-1]} + b^{[L]}, \quad A^{[L]} = g^{[L]}(Z^{[L]}) = \hat{Y}$$

10.2 Backward propagation (vectorized)

$$dZ^{[L]} = A^{[L]} - Y$$ $$dW^{[L]} = \frac{1}{m} dZ^{[L]} A^{[L-1]T}, \quad db^{[L]} = \frac{1}{m}\texttt{sum}(dZ^{[L]})$$ $$dZ^{[L-1]} = W^{[L]T} dZ^{[L]} * g^{[L-1]\prime}(Z^{[L-1]})$$ $$\vdots$$ $$dZ^{[1]} = W^{[2]T} dZ^{[2]} * g^{[1]\prime}(Z^{[1]})$$ $$dW^{[1]} = \frac{1}{m} dZ^{[1]} X^T, \quad db^{[1]} = \frac{1}{m}\texttt{sum}(dZ^{[1]})$$
⭐ Key Idea — the symmetry of forward and backward

Forward goes input → output, computing activations. Backward goes output → input, computing gradients. Both are loops over the $L$ layers; both use exactly the same parameters. This symmetry is the elegant structure at the heart of deep learning.

⚙️ Implementation — the full training loop
# Pseudocode for one epoch of training
for i in range(num_iterations):
    # Forward pass — store caches
    AL, caches = forward_propagation(X, params)
    
    # Compute cost
    cost = compute_cost(AL, Y)
    
    # Backward pass
    grads = backward_propagation(AL, Y, caches)
    
    # Update parameters
    for l in range(1, L + 1):
        params[f"W{l}"] -= learning_rate * grads[f"dW{l}"]
        params[f"b{l}"] -= learning_rate * grads[f"db{l}"]

11. Parameters vs Hyperparameters

🔵 Definition — Parameters

Parameters are the values the network learns from data during training. Examples: $W^{[1]}, b^{[1]}, W^{[2]}, b^{[2]}, \ldots, W^{[L]}, b^{[L]}$. These are updated by gradient descent.

🔵 Definition — Hyperparameters

Hyperparameters are settings that you choose — they control how the parameters are learned, but are not themselves updated by gradient descent. Examples: learning rate, number of iterations, number of hidden layers, number of hidden units per layer, choice of activation function.

💡 Insight — why the distinction matters

You can't "train" hyperparameters with gradient descent the same way you train parameters — because the cost function is usually not differentiable with respect to them, or they're discrete choices. Instead, you tune hyperparameters empirically: try a value, run training, see how the cost behaves, and try again. This is the essence of applied deep learning.

⭐ Key Idea — some advanced hyperparameters

In later courses and in practice, you'll encounter more hyperparameters:

  • Momentum coefficient — smooths gradient updates.
  • Mini-batch size — how many examples per gradient step.
  • Regularization strength (λ) — penalizes large weights to prevent overfitting.
  • Learning rate decay parameters — schedule for shrinking α over time.

These all fall under the same "hyperparameter" umbrella: values you choose to guide training.

12. Deep Learning is an Empirical Process

How do you actually pick good hyperparameters? There's no magic formula — it's an iterative, empirical process.

🟢 Intuition — why it's empirical

Deep-learning models are complicated nonlinear systems. Unlike classical statistics, there's no closed-form formula that tells you the right learning rate for a given problem. The only reliable way is to run experiments and observe the results. Andrew emphasizes: "Applied deep learning is a very empirical process."

12.1 Diagnosing from the learning curve

One of the most useful practical skills is reading the cost-vs-iterations plot.

💡 Insight — how to actually tune

Try a few values of α on a logarithmic scale: 0.1, 0.03, 0.01, 0.003, 0.001, … Plot the cost curve for each. Pick the largest α that still gives a smooth decreasing curve. This is the kind of empirical loop Andrew is describing.

13. What Does This Have to Do with the Brain?

There's a common narrative: "neural networks are inspired by the brain." Andrew addresses this directly — and the takeaway is subtle but important.

Historically, deep learning drew some inspiration from neuroscience. But the analogy is loose at best:

  • Real neurons are vastly more complex than the simple "weighted sum + activation" model.
  • Real brains use sophisticated mechanisms (timing, spiking, plasticity, neuromodulators) that artificial neurons don't capture.
  • Modern deep-learning architectures (CNNs, transformers) are driven mostly by mathematical and engineering considerations, not by neuroscience.
💡 Insight — Andrew's honest framing

Andrew's stance is: while the brain-inspired story is interesting, we should treat artificial neurons as mathematical functions, not as simulations of the brain. This framing has been far more productive for engineering. Don't over-claim the brain analogy.

⭐ Key Idea — why this matters

If you think of a neural network as "the brain," you may expect it to have brain-like properties (interpretability, general intelligence). If you think of it as a powerful function approximator trained by gradient descent, you'll be more clear-eyed about what it can and can't do. Andrew favors the second framing.

14. Common Mistakes & Clarifications

🔴 Mistake 1 — Confusing depth with number of hidden layers

$L$ counts all layers (hidden + output). A network with 1 hidden layer is $L = 2$. Be careful when someone says "a 2-layer NN" — always clarify if they count the input.

🔴 Mistake 2 — Getting shapes wrong

$W^{[l]}$ has shape $(n^{[l]}, n^{[l-1]})$, and $b^{[l]}$ has shape $(n^{[l]}, 1)$. If a shape mismatch error appears, check these two rules first.

🔴 Mistake 3 — Forgetting to cache during forward pass

The backward pass needs $Z^{[l]}$, $A^{[l-1]}$, $W^{[l]}$, $b^{[l]}$. If you don't cache these during forward propagation, you'll have to recompute them — much slower, and error-prone.

🔴 Mistake 4 — Using the same activation everywhere

Different layers often benefit from different activations: ReLU for hidden layers, sigmoid (or softmax) for the output layer of a classifier. The choice is itself a hyperparameter.

🔴 Mistake 5 — Thinking more depth always helps

Deeper isn't automatically better. Very deep networks are harder to train (vanishing/exploding gradients, more hyperparameters). Depth helps when used with the right techniques — a theme for Course 2.

🔴 Mistake 6 — Treating hyperparameters like parameters

You don't update hyperparameters with gradient descent. You choose them, run experiments, and iterate. This is the "empirical process" Andrew emphasizes.

🔴 Mistake 7 — Over-interpreting the brain analogy

Artificial neurons are simplified mathematical functions, not biological simulations. Treating them as "mini-brains" leads to confusion about what they can do.

15. Weekly Summary & Review

📌 Weekly Summary

1. Deep neural networks. A deep network has $L$ layers (hidden + output). A "1-hidden-layer" network is $L = 2$. "Deep" means many layers.

2. Notation. $L$ = number of layers; $n^{[l]}$ = units in layer $l$; $a^{[l]}$ = activation of layer $l$; $W^{[l]}$ shape $(n^{[l]}, n^{[l-1]})$; $b^{[l]}$ shape $(n^{[l]}, 1)$; $a^{[0]} = x$; $a^{[L]} = \hat{y}$.

3. Forward propagation. For $l = 1, \ldots, L$: $z^{[l]} = W^{[l]}a^{[l-1]} + b^{[l]}$, $a^{[l]} = g^{[l]}(z^{[l]})$. Vectorized over examples: $Z^{[l]} = W^{[l]}A^{[l-1]} + b^{[l]}$, $A^{[l]} = g^{[l]}(Z^{[l]})$.

4. Matrix dimensions. $W^{[l]}$ is $(n^{[l]}, n^{[l-1]})$, $b^{[l]}$ is $(n^{[l]}, 1)$. Forward pass: $Z^{[l]}$ has shape $(n^{[l]}, m)$. Always assert shapes in code.

5. Why depth helps. Deep networks learn hierarchical features — edges → parts → objects → scenes. Each layer composes the previous. In circuit theory, some functions need exponentially more units if computed by a shallow network.

6. Building blocks. Each layer has a forward function (computes activations, caches values) and a backward function (computes gradients). Deep networks are just a loop over these blocks.

7. Backward propagation for layer l. $dz^{[l]} = da^{[l]} * g^{[l]\prime}(z^{[l]})$; $dW^{[l]} = dz^{[l]} a^{[l-1]T}$; $db^{[l]} = dz^{[l]}$; $da^{[l-1]} = W^{[l]T}dz^{[l]}$.

8. Parameters vs hyperparameters. Parameters ($W, b$) are learned by gradient descent. Hyperparameters (learning rate, network size, activation choice) are chosen by you and tuned empirically.

9. Empirical process. Applied DL is iterative: form an idea, code it, run experiments, analyze results, iterate. Reading the cost-vs-iterations curve is a key diagnostic skill.

10. Brain analogy. Artificial neurons are mathematical functions, not brain simulations. Treat them as function approximators trained by gradient descent.

📝 Quick Review (Click to Reveal Answers)

What is a "deep" neural network?
A neural network with many layers (typically more than one hidden layer). "Deep" refers to the number of layers, not the complexity of individual neurons.
How many layers does a network with 3 hidden layers and 1 output layer have?
$L = 4$. The convention counts hidden + output layers.
What does $n^{[l]}$ denote?
The number of units (neurons) in layer $l$.
What is the shape of $W^{[l]}$?
$(n^{[l]}, n^{[l-1]})$ — rows = units in layer $l$, columns = units in layer $l-1$.
Write the forward propagation equations for layer $l$.
$z^{[l]} = W^{[l]}a^{[l-1]} + b^{[l]}$ and $a^{[l]} = g^{[l]}(z^{[l]})$.
What is the shape of $A^{[l]}$ when vectorized over $m$ examples?
$(n^{[l]}, m)$ — one column per example.
Why do we cache values during the forward pass?
Because the backward pass needs values like $z^{[l]}$ and $a^{[l-1]}$ to compute gradients. Caching avoids recomputation.
Explain why deep representations help, using the face-recognition example.
Early layers detect simple features (edges). Middle layers combine edges into parts (eyes, nose). Later layers combine parts into whole objects (faces). This hierarchical composition lets each layer build increasingly abstract representations.
What does circuit theory say about the value of depth?
Some functions can be computed by small deep networks but require exponentially more hidden units in a shallow network. Depth gives exponential efficiency for compositional functions.
In the XOR example, how does a deep network's cost compare to a shallow one?
A deep network can compute XOR of $n$ inputs with depth $O(\log n)$ and width $O(n)$. A shallow network needs $O(2^n)$ hidden units — exponentially more.
Write the backward propagation equations for layer $l$.
$dz^{[l]} = da^{[l]} * g^{[l]\prime}(z^{[l]})$, $dW^{[l]} = dz^{[l]} a^{[l-1]T}$, $db^{[l]} = dz^{[l]}$, $da^{[l-1]} = W^{[l]T} dz^{[l]}$.
Why is the transpose used in $da^{[l-1]} = W^{[l]T} dz^{[l]}$?
Because forward propagation uses $W^{[l]}$ to go from layer $l-1$ to layer $l$. To propagate the error backward, we need the transpose — it "reverses" the direction of information flow through the same weights.
What is the difference between a parameter and a hyperparameter?
Parameters ($W, b$) are learned from data by gradient descent. Hyperparameters (learning rate, network size, activation choice) are set by the practitioner and tuned empirically.
List four hyperparameters of a deep neural network.
Any four of: learning rate α, number of iterations, number of hidden layers L, number of hidden units per layer, choice of activation function, mini-batch size, regularization strength, momentum coefficient.
Why is applied deep learning described as "empirical"?
Because there's no closed-form way to know the best hyperparameters for a given problem. You must run experiments, observe results (e.g., cost curves), and iterate.
If cost is decreasing very slowly, what might be wrong?
The learning rate α might be too small. Try increasing it by a factor of 3 or 10 and re-run.
If cost oscillates or increases, what's likely wrong?
The learning rate α is probably too large. Try decreasing it.
What is the correct interpretation of the "brain analogy" for neural networks?
Artificial neurons are simplified mathematical functions, not biological simulations. The brain-inspired narrative is historically interesting but not a productive frame for understanding what modern deep networks do.
What is the difference between "shallow" and "deep" networks?
Shallow networks have few layers (often just one hidden layer). Deep networks have many. "Deep" refers to the number of layers in the network.
Why does vectorization matter in deep networks, not just in shallow ones?
Because deep networks still process each example independently. Vectorization across examples (matrix multiplication) makes training feasible even for very deep networks and large datasets.

🧠 Self-Test (Conceptual)

You build a network with 5 hidden layers, each with 100 units, and 1 output unit. How many layers L? What are the shapes of $W^{[1]}, W^{[2]}, W^{[3]}, W^{[4]}, W^{[5]}, W^{[6]}$ assuming 20 input features?
$L = 6$ (5 hidden + 1 output). $W^{[1]}$: $(100, 20)$; $W^{[2]}, W^{[3]}, W^{[4]}, W^{[5]}$: $(100, 100)$; $W^{[6]}$: $(1, 100)$.
Your gradient-descent training produces NaN values after a few iterations. Where might you look first?
Two common causes: (1) the learning rate is too large (updates overshoot and blow up); (2) log(0) or 0/0 in the cost computation (log of 0 or division by 0). Reduce α and/or use numerically stable cost formulas.
You have two models: one with 3 hidden layers (each 100 units), one with 1 hidden layer (1000 units). Both have similar parameter counts. Which would you expect to perform better on a complex image classification task, and why?
The deeper one, generally. Depth provides feature hierarchy — early layers detect simple features, deeper layers detect complex ones. Circuit theory suggests certain functions are exponentially cheaper with depth. In practice, deep networks tend to perform better on structured data like images.
Someone says: "I'll just use a very wide single hidden layer to avoid the complications of deep networks." What's the trade-off?
Wide shallow networks can approximate many functions (universal approximation theorem), but for compositional functions, they may need exponentially more units — meaning far more parameters and more data to train. Depth is often more parameter-efficient, though it introduces training challenges (vanishing gradients, more hyperparameters).
Why does backpropagation reuse the same $W^{[l]}$ and $b^{[l]}$ from the forward pass?
Because they're the same parameters. The gradients tell us how to adjust them; there's only one set of parameters that defines the network's function. Backprop doesn't create new parameters — it computes derivatives w.r.t. the parameters already used.
During backprop, you compute $dA^{[l-1]}$ but only need it to compute gradients for layer $l-1$. What happens for the input layer (i.e., when $l = 1$)?
You don't compute $dA^{[0]}$ — the input is fixed, so we stop. In practice, you just don't propagate the gradient past layer 1.
What hyperparameter would you tune first if your training cost doesn't decrease at all in the first 100 iterations?
Learning rate α. If cost is stuck, α may be too small (very slow progress) or too large (diverge). Also check that gradients are being computed correctly, and that the initialization isn't degenerate (e.g., all zeros).
Why might a practitioner prefer to think of neural networks as mathematical functions rather than brain models?
Because they're actually trained as function approximators via gradient descent. The "brain" framing leads to expectations (interpretability, general intelligence) that are not warranted. The mathematical framing keeps you focused on what the network does: mapping inputs to outputs through a parameter
