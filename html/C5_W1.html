Recurrent Neural Networks (RNNs)

Course 5 · Week 1 — a complete, beginner-friendly walkthrough. Everything you need, explained from first principles.

1. Why Sequence Models?

Imagine you are building a system that reads a sentence word by word, or listens to an audio clip, or watches a video. In all these cases, the data is not a single fixed-size snapshot — it is a sequence: an ordered list of things where order matters.

Big idea

“Dog bites man” and “Man bites dog” contain the same words, but they mean completely different things. Order carries meaning. A standard neural network has no built-in way to respect order — that is exactly the problem sequence models solve.

Real examples from the slides

TaskInput (x)Output (y)
Speech recognitionAudio waveform“The quick brown fox jumped over the lazy dog.”
Music generationNothing / a seed noteA sequence of musical notes
Sentiment classification“There is nothing to like in this movie.”★ (1 star) or 0/1 rating
DNA sequence analysisAGCCCCTGTGAGGAACTAGWhich part is a protein-coding region
Machine translation“Voulez-vous chanter avec moi?”“Do you want to sing with me?”
Video activity recognitionA sequence of video frames“Running”
Named entity recognition“Yesterday, Harry Potter met Hermione Granger.”Highlight which words are person names

Why not use a standard (fully-connected) neural network?

Two big problems:

  1. Variable lengths. Sentences have different numbers of words. A standard network expects a fixed-size input vector, so you would have to pad or truncate — both hurt performance.
  2. No weight sharing across positions. If the network learns that “Harry” at position 1 is a name, that knowledge does not automatically transfer to “Harry” at position 5. A standard network treats each position with a separate set of weights.

2. Notation

Before we build an RNN, we need a consistent way to write down sequences. Let us use the sentence from the slides:

“Harry Potter and Hermione Granger invented a new spell.”

2.1 The superscript notation ⟨t⟩

We write x<t> to mean “the input at time step t.” So:

$$x^{\langle 1\rangle}=\text{Harry},\; x^{\langle 2\rangle}=\text{Potter},\; x^{\langle 3\rangle}=\text{and},\; \dots,\; x^{\langle 9\rangle}=\text{spell}$$
  • x<t> — the input at time step t (one word).
  • y<t> — the output at time step t (one label).
  • Tx — the length of the input sequence (here 9 words).
  • Ty — the length of the output sequence (can differ from Tx).
  • x(i)<t> — the input at step t of the i-th training example.
  • y(i)<t> — the output at step t of the i-th training example.
Watch out

The angle-bracket superscript <t> means time step. A round bracket (i) means which training example. Do not confuse them: x(i)<t> = time step t of example i.

2.2 Representing words: one-hot vectors

Neural networks work with numbers, not words. So we build a vocabulary — a list of all unique words in our training data — and assign each word an index.

Example vocabulary from the slides (size = 10,000):

WordIndex
a1
aaron2
and367
harry4075
potter6830
……
zulu10,000

A one-hot vector is a vector of length |V| (vocabulary size) that is all zeros except for a single 1 at the index of the word.

$$x^{\langle 1\rangle}=\begin{bmatrix}0\\0\\\vdots\\1\\\vdots\\0\end{bmatrix}\leftarrow \text{position 4075 (Harry)}$$
Practical note

One-hot vectors are easy but wasteful: a 10,000-word vocabulary needs 10,000-dimensional vectors, each mostly zeros. Later in the course you will see word embeddings that compress this into a few hundred meaningful numbers — but for building the RNN, one-hot is the standard starting point.

3. Recurrent Neural Network Model

An RNN processes a sequence one time step at a time, and at each step it carries forward a hidden state — a summary of everything it has seen so far.

Analogy

Imagine reading a book. You do not re-read every earlier page each time you turn one. Instead, your brain maintains a running “memory” of the story so far. When you read a new sentence, you combine it with that memory. The RNN’s hidden state a<t> is exactly that running memory.

3.1 The unrolled RNN

The same cell is applied repeatedly — once per time step. Drawing it “unrolled” (left to right) makes this clear.

3.2 Why weight sharing matters

Because the same weights are reused at every time step, the network learns one general rule (“how does a word combine with the memory so far?”) and applies it everywhere. This gives two huge benefits:

  • It works for any sequence length. The same cell handles a 3-word sentence or a 300-word paragraph.
  • Features transfer across positions. If the network learns what “Harry” looks like at step 1, it recognises it at step 5 too.

3.3 The “Teddy Roosevelt” motivating example

The slides give a classic example of why context matters:

  • “He said, ‘Teddy Roosevelt was a great President.’” → “Teddy” is part of a person’s name.
  • “He said, ‘Teddy bears are on sale!’” → “Teddy” is part of a toy name.

The word “Teddy” is identical in both. Only the words that follow it disambiguate. An RNN carries the context forward, so a later decision (or a bidirectional RNN, see §12) can use that context.

4. Forward Propagation in an RNN

Forward propagation is the process of computing outputs from inputs, step by step. Here is the full recipe.

4.1 Initialising

$$a^{\langle 0\rangle}=\vec{0}$$

We start with a zero vector as the “memory before reading anything.”

4.2 The two core equations

Step 1 — update the hidden state:

$$a^{\langle t\rangle}=g_1\!\left(W_{aa}\,a^{\langle t-1\rangle}+W_{ax}\,x^{\langle t\rangle}+b_a\right)$$

Step 2 — produce the output:

$$\hat{y}^{\langle t\rangle}=g_2\!\left(W_{ya}\,a^{\langle t\rangle}+b_y\right)$$

4.3 What every symbol means

SymbolMeaningTypical shape
a<t>hidden state (memory) at step t(100, 1)
x<t>input at step t (one-hot word)(10,000, 1)
Waaweights mapping previous hidden state → new hidden state(100, 100)
Waxweights mapping current input → new hidden state(100, 10,000)
Wyaweights mapping hidden state → output(|V|, 100) for classification
ba, bybias vectors(100, 1), (|V|, 1)
g1activation — usually tanh or ReLU—
g2output activation — sigmoid for binary, softmax for multi-class—
Read the equation in plain English

“The new memory is a nonlinear blend of two things: what I remembered before (scaled by Waa) and what I just read (scaled by Wax), plus a bias.”

4.4 Simplified notation

Writing Waa and Wax separately gets tiring. The slides introduce a neat shorthand: stack the two matrices side-by-side and stack the two vectors on top of each other.

$$W_a=\big[\,W_{aa}\;\big|\;W_{ax}\,\big],\qquad \big[a^{\langle t-1\rangle},\,x^{\langle t\rangle}\big]=\begin{bmatrix}a^{\langle t-1\rangle}\\[2pt]x^{\langle t\rangle}\end{bmatrix}$$

Then the hidden-state update becomes one clean matrix multiply:

$$\boxed{\,a^{\langle t\rangle}=g\!\left(W_a\big[a^{\langle t-1\rangle},\,x^{\langle t\rangle}\big]+b_a\right)\,}$$

and similarly:

$$\boxed{\,\hat{y}^{\langle t\rangle}=g\!\left(W_y\,a^{\langle t\rangle}+b_y\right)\,}$$
Why this works

Splitting a matrix product into two pieces and adding them is the same as concatenating the inputs and multiplying once. The dimensions add up: Waa is (100, 100), Wax is (100, 10,000), so Wa is (100, 10,100). And a<t−1> is length 100, x<t> is length 10,000, so the stacked vector is length 10,100. It fits perfectly.

4.5 Worked micro-example

Suppose we have a tiny vocabulary of 3 words and a hidden state of size 2:

Waa = [[0.5, 0.1],    a<t-1> = [[0.2],
       [0.2, 0.4]]                [0.3]]

Wax = [[0.1, 0.6, 0.3],   x<t> = [[1],   (one-hot of word "and")
       [0.4, 0.2, 0.5]]             [0],
                                    [0]]

ba = [[0.05],[0.05]]

Step 1: Waa · a<t-1> = [0.5*0.2 + 0.1*0.3, 0.2*0.2 + 0.4*0.3] = [0.13, 0.16]
Step 2: Wax · x<t>  = [0.1, 0.4]   (only first column since x is one-hot at 1)
Step 3: sum + ba    = [0.13+0.1+0.05, 0.16+0.4+0.05] = [0.28, 0.61]
Step 4: tanh        = [0.273, 0.544]   →  a<t>

That's one time step. Repeat for every word in the sentence, feeding the new hidden state forward.

5. Backpropagation Through Time

Training an RNN uses the same idea as training any neural network — gradient descent on a loss function — but the gradients must flow backwards through the whole sequence.

5.1 The loss for one time step

If the output is a single number (e.g., binary classification), we use the cross-entropy loss:

$$\mathcal{L}^{\langle t\rangle}\big(\hat{y}^{\langle t\rangle},\,y^{\langle t\rangle}\big)=-\,y^{\langle t\rangle}\log\hat{y}^{\langle t\rangle}-\big(1-y^{\langle t\rangle}\big)\log\big(1-\hat{y}^{\langle t\rangle}\big)$$

If the output is a distribution over a vocabulary (language model), we use the sum over all words:

$$\mathcal{L}^{\langle t\rangle}\big(\hat{y}^{\langle t\rangle},\,y^{\langle t\rangle}\big)=-\sum_{i}y_i^{\langle t\rangle}\log\hat{y}_i^{\langle t\rangle}$$

5.2 Total loss

We add up the loss at every time step:

$$\mathcal{L}(\hat{y},\,y)=\sum_{t=1}^{T_y}\mathcal{L}^{\langle t\rangle}\big(\hat{y}^{\langle t\rangle},\,y^{\langle t\rangle}\big)$$

5.3 What “through time” means

To update Waa, we need ∂L/∂Waa. But a<t> depends on a<t−1>, which depends on a<t−2>, and so on. So the gradient must be propagated backwards through every time step — hence the name backpropagation through time (BPTT).

7. Language Modelling and Sequence Generation

7.1 What is a language model?

A language model answers the question: “How likely is this sentence?” More precisely, it estimates

$$P(y^{\langle 1\rangle},y^{\langle 2\rangle},\dots,y^{\langle T_y\rangle})$$

— the probability of a whole sequence of words.

Why it matters

In speech recognition, the audio might sound like either “The apple and pair salad” or “The apple and pear salad.” A language model tells you the second is far more likely:

$$P(\text{The apple and pair salad})=3.2\times10^{-13}$$ $$P(\text{The apple and pear salad})=5.7\times10^{-10}$$

The speech recogniser then picks the more probable one.

7.2 Building a language model with an RNN

Training data: a large corpus of English text.

Step 1 — Tokenise. Split the text into words (or characters).

"Cats average 15 hours of sleep a day."
→ ["Cats", "average", "15", "hours", "of", "sleep", "a", "day", "."]

Also add an <EOS> (end of sentence) token at the end, and an <UNK> token for rare/unknown words.

Step 2 — Set x<t> = y<t−1>. The input at step t is the output at step t−1. At step 1, the input is a special start token (or zero vector).

Step 3 — Train the RNN to predict the next word. At each step, the network outputs a probability distribution over the vocabulary for what comes next. The loss compares this distribution to the actual next word.

7.3 The loss function

At each step we apply a softmax to get a probability distribution, then use the cross-entropy loss:

$$\mathcal{L}^{\langle t\rangle}(\hat{y}^{\langle t\rangle},y^{\langle t\rangle})=-\sum_i y_i^{\langle t\rangle}\log\hat{y}_i^{\langle t\rangle}$$

And the total loss over the sequence is the sum:

$$\mathcal{L}=\sum_t \mathcal{L}^{\langle t\rangle}(\hat{y}^{\langle t\rangle},y^{\langle t\rangle})$$

7.4 The chain rule of probability

The RNN’s output at each step is a conditional probability. Multiplying them together gives the probability of the whole sentence:

$$P(y^{\langle 1\rangle},y^{\langle 2\rangle},y^{\langle 3\rangle})=P(y^{\langle 1\rangle})\,P(y^{\langle 2\rangle}\mid y^{\langle 1\rangle})\,P(y^{\langle 3\rangle}\mid y^{\langle 1\rangle},y^{\langle 2\rangle})$$

This is exactly what the RNN computes, one factor at a time.

8. Sampling Novel Sequences

Once a language model is trained, we can use it to generate new text — one word at a time.

8.1 Training vs. sampling

8.2 The sampling algorithm

  1. Start with a<0> = 0 and x<1> = 0 (or a special start token).
  2. Run one forward step to get ŷ<1>, a probability distribution over the vocabulary.
  3. Randomly sample a word from that distribution (np.random.choice).
  4. Feed the sampled word as the input for the next step.
  5. Repeat until the <EOS> token is sampled or a maximum length is reached.

8.3 Character-level language models

Instead of words, we can build a model over individual characters. The vocabulary becomes much smaller (e.g., a–z, A–Z, punctuation), but the sequences become much longer.

Word-levelCharacter-level
Vocabulary size~10,000+~100
Sequence lengthShorterMuch longer
Risk of <UNK>Yes — rare wordsNo — can spell anything

Character-level models can generate surprisingly Shakespeare-like text, as the slide shows, but they sometimes produce nonsensical words. Word-level models are more coherent but limited by the vocabulary.

Two special tokens
  • <EOS> — end of sentence. Signals generation to stop.
  • <UNK> — unknown. Replaces any word not in the vocabulary.

9. Vanishing Gradients with RNNs

Plain RNNs have a serious training problem: gradients can shrink (or blow up) exponentially as they flow backwards through many time steps.

9.1 The motivating sentence

Consider:

  • “The cat, which already ate ……, was full.” (singular)
  • “The cats, which already ate ……, were full.” (plural)

To pick the right verb (“was” vs. “were”), the network must remember whether the subject was singular or plural — a fact from many steps earlier. A plain RNN struggles to carry that information across a long gap.

9.2 Exploding gradients

Sometimes gradients do the opposite — they grow exponentially. This is called the exploding gradient problem, and it shows up as NaN values during training.

Practical fix

Gradient clipping is the standard remedy for exploding gradients: if the gradient vector’s norm exceeds a threshold, rescale it back down. Vanishing gradients are harder to fix directly — which is why GRUs and LSTMs were invented.

10. Gated Recurrent Unit (GRU)

The GRU, introduced by Cho et al. (2014), solves the vanishing gradient problem by adding gates — small neural networks that decide how much old information to keep and how much new information to write.

10.1 The plain RNN unit, for comparison

In a plain RNN, the hidden state is simply overwritten every step:

$$a^{\langle t\rangle}=g\!\left(W_a[a^{\langle t-1\rangle},x^{\langle t\rangle}]+b_a\right)$$

There is no choice — whatever the new computation produces becomes the new memory, and the old memory is completely discarded.

10.2 The GRU’s key idea: the memory cell

Analogy

Think of the GRU as having a notebook (the memory cell c<t>). At each step, a gate decides: “Should I erase what is written and write something new, or just leave it alone?” For long stretches where nothing important happens, the gate stays “off” and the old memory is preserved unchanged — no gradient dilution.

10.3 The (simplified) GRU equations

In the simplified GRU shown in the slides, c<t> = a<t> — the memory cell and hidden state are the same thing.

$$\tilde{c}^{\langle t\rangle}=\tanh\!\left(W_c\big[c^{\langle t-1\rangle},x^{\langle t\rangle}\big]+b_c\right)$$

The candidate new memory — what we could write.

$$\Gamma_u=\sigma\!\left(W_u\big[c^{\langle t-1\rangle},x^{\langle t\rangle}\big]+b_u\right)$$

The update gate. A number between 0 and 1 that decides how much of the candidate to accept.

$$\boxed{\,c^{\langle t\rangle}=\Gamma_u * \tilde{c}^{\langle t\rangle}+\big(1-\Gamma_u\big) * c^{\langle t-1\rangle}\,}$$

The actual memory update. If Γu = 1, we completely replace the memory with the candidate. If Γu = 0, we keep the old memory untouched.

$$a^{\langle t\rangle}=c^{\langle t\rangle}$$

10.4 Why this helps

In a plain RNN, the hidden state is recomputed from scratch at every step. In a GRU, the (1 − Γu) * c<t−1> term creates a direct path for the old memory to flow forward without being multiplied by weight matrices. This path is what allows gradients to survive across many time steps.

10.5 The full GRU

The full GRU adds one more gate, the relevance gate Γr, which controls how much of the previous hidden state is used when computing the candidate:

$$\tilde{c}^{\langle t\rangle}=\tanh\!\left(W_c\big[\Gamma_r * c^{\langle t-1\rangle},\,x^{\langle t\rangle}\big]+b_c\right)$$ $$\Gamma_u=\sigma\!\left(W_u\big[c^{\langle t-1\rangle},x^{\langle t\rangle}\big]+b_u\right)$$ $$\Gamma_r=\sigma\!\left(W_r\big[c^{\langle t-1\rangle},x^{\langle t\rangle}\big]+b_r\right)$$ $$c^{\langle t\rangle}=\Gamma_u * \tilde{c}^{\langle t\rangle}+\big(1-\Gamma_u\big) * c^{\langle t-1\rangle}$$ $$a^{\langle t\rangle}=c^{\langle t\rangle}$$

In this form, Γr is called the relevance gate (sometimes reset gate). It lets the cell decide how much of the past is relevant to the new candidate.

11. Long Short-Term Memory (LSTM)

The LSTM, introduced by Hochreiter & Schmidhuber (1997), is a more powerful and more general cousin of the GRU. It uses three gates instead of two, and it keeps the memory cell and the hidden state separate.

11.1 The three gates

GateSymbolWhat it controls
Update gateΓuHow much of the new candidate to write into memory
Forget gateΓfHow much of the old memory to keep
Output gateΓoHow much of the memory to expose as the hidden state

11.2 The LSTM equations

$$\tilde{c}^{\langle t\rangle}=\tanh\!\left(W_c\big[a^{\langle t-1\rangle},x^{\langle t\rangle}\big]+b_c\right)$$ $$\Gamma_u=\sigma\!\left(W_u\big[a^{\langle t-1\rangle},x^{\langle t\rangle}\big]+b_u\right)$$ $$\Gamma_f=\sigma\!\left(W_f\big[a^{\langle t-1\rangle},x^{\langle t\rangle}\big]+b_f\right)$$ $$\Gamma_o=\sigma\!\left(W_o\big[a^{\langle t-1\rangle},x^{\langle t\rangle}\big]+b_o\right)$$ $$c^{\langle t\rangle}=\Gamma_u * \tilde{c}^{\langle t\rangle}+\Gamma_f * c^{\langle t-1\rangle}$$ $$a^{\langle t\rangle}=\Gamma_o * \tanh\!\big(c^{\langle t\rangle}\big)$$
Key difference from GRU

In the GRU, the memory update used (1 − Γu) as the “keep” coefficient — it was tied to the update gate. In the LSTM, the forget gate Γf is independent. This gives the LSTM more flexibility: it can simultaneously write a lot of new information and keep a lot of old information.

11.3 GRU vs. LSTM — which to use?

GRULSTM
Number of gates23
Memory cellSame as hidden state (c = a)Separate from hidden state
ParametersFewerMore
Training speedFasterSlower
PerformanceOften comparableMore powerful on long-range tasks
Typical choiceSmaller datasets, speed mattersLarger datasets, deeper dependencies

The slides note that there is no universally best choice. Many practitioners try both and pick based on validation performance.

12. Bidirectional RNN (BRNN)

A standard RNN reads left to right. But sometimes the future is needed to correctly classify the present.

The Teddy problem again

“He said, ‘Teddy ___ …’” — to decide whether “Teddy” is part of a name or a toy, you need to see the next word (“Roosevelt” vs. “bears”). A left-to-right RNN does not have that information when it processes “Teddy”. A bidirectional RNN fixes this.

12.1 How it works

A bidirectional RNN runs two RNNs in parallel:

  • A forward RNN that reads the sequence left → right, producing a→<t>.
  • A backward RNN that reads the sequence right → left, producing a←<t>.

At each time step, the outputs of both are concatenated and used to make the prediction.

$$\hat{y}^{\langle t\rangle}=g\!\left(W_y\big[\,\overrightarrow{a}^{\langle t\rangle},\,\overleftarrow{a}^{\langle t\rangle}\,\big]+b_y\right)$$

12.2 When to use BRNNs

BRNNs are excellent for tasks where the entire sequence is available at once — named entity recognition, sentiment classification, machine translation encoding. They cannot be used for real-time generation (like predicting the next word as you type) because the future is not available.

Important caveat

The bidirectional architecture can use RNN, GRU, or LSTM cells as its building block. The choice of cell and the choice of directionality are independent design decisions.

13. Deep RNNs

Just like ordinary neural networks, RNNs can be stacked into multiple layers. Each layer processes the sequence produced by the layer below.

13.1 The architecture

If layer [l] produces hidden states a[l]<t>, then layer [l+1] uses those as its inputs:

$$a^{[l]\langle t\rangle}=g\!\left(W_a^{[l]}\big[a^{[l]\langle t-1\rangle},\,a^{[l-1]\langle t\rangle}\big]+b_a^{[l]}\right)$$
Why not go very deep?

A 3-layer RNN already has a temporal dimension of length Tx at every layer — so the effective depth is layers × Tx. This makes deep RNNs far more expensive to train than deep feedforward networks, and the usual practice is to keep the stack shallow (2–4 layers) unless the task demands more.

14. Self-Test

Try each question on paper before revealing the answer.

Q1. What is the difference between x<t> and x(i)<t>?
Show answer

x<t> is the input at time step t — a single item in the sequence. x(i)<t> is the input at time step t of the i-th training example. The angle brackets index time; the parentheses index which example in the dataset.

Q2. Why does an RNN share weights across time steps?
Show answer

Sharing weights means the same cell (the same Waa, Wax, Wya) is applied at every time step. This (1) allows the network to handle sequences of any length, and (2) lets features learned at one position generalise to other positions. Without sharing, a standard network would need a separate set of weights for each position and would fail on variable-length inputs.

Q3. Write the two forward-propagation equations of a plain RNN.
Show answer

$$a^{\langle t\rangle}=g_1\!\left(W_{aa}a^{\langle t-1\rangle}+W_{ax}x^{\langle t\rangle}+b_a\right)$$

$$\hat{y}^{\langle t\rangle}=g_2\!\left(W_{ya}a^{\langle t\rangle}+b_y\right)$$

Or in simplified notation:

$$a^{\langle t\rangle}=g\!\left(W_a[a^{\langle t-1\rangle},x^{\langle t\rangle}]+b_a\right),\quad \hat{y}^{\langle t\rangle}=g\!\left(W_y a^{\langle t\rangle}+b_y\right)$$

Q4. What is the loss function used for a language model RNN?
Show answer

At each time step, cross-entropy over the vocabulary:

$$\mathcal{L}^{\langle t\rangle}=-\sum_i y_i^{\langle t\rangle}\log\hat{y}_i^{\langle t\rangle}$$

The total loss is the sum over all time steps: $$\mathcal{L}=\sum_t\mathcal{L}^{\langle t\rangle}$$

Q5. What is “teacher forcing” and why is it used?
Show answer

During training, the input at step t is set to the correct previous word from the corpus (x<t> = y<t−1>). This is teacher forcing. It stabilises training because the network always sees the true context rather than its own (possibly wrong) predictions. At sampling time, teacher forcing is removed and the network feeds its own sampled outputs back in.

Q6. Why do plain RNNs suffer from vanishing gradients?
Show answer

During backpropagation through time, the gradient is repeatedly multiplied by the weight matrix Waa and the derivative of the activation function. If these factors are consistently less than 1, the product shrinks exponentially with the number of time steps, so contributions from early time steps become negligible. The network then cannot learn long-range dependencies.

Q7. What is the difference between the GRU update rule and the LSTM update rule?
Show answer

GRU: $$c^{\langle t\rangle}=\Gamma_u * \tilde{c}^{\langle t\rangle}+(1-\Gamma_u)*c^{\langle t-1\rangle}$$ — the “keep” coefficient is (1 − Γu), tied to the update gate.

LSTM: $$c^{\langle t\rangle}=\Gamma_u * \tilde{c}^{\langle t\rangle}+\Gamma_f * c^{\langle t-1\rangle}$$ — the forget gate Γf is independent, giving the LSTM more flexibility.

Also, in a GRU c<t> = a<t>; in an LSTM c<t> and a<t> are separate, with a<t> = Γo * tanh(c<t>).

Q8. What is the purpose of the output gate in an LSTM?
Show answer

The output gate Γo decides how much of the (tanh-squashed) memory cell c<t> is exposed as the hidden state a<t>. This lets the cell store information internally without necessarily broadcasting it to the rest of the network at every step.

Q9. When would you use a bidirectional RNN instead of a unidirectional one?
Show answer

Use a BRNN when the entire input sequence is available at prediction time and future context helps disambiguate the present — e.g., named entity recognition, sentiment classification, or the encoder of a machine translation model. Do not use it for real-time generation, where future words are not yet known.

Q10. Why are deep RNNs typically kept shallow (2–4 layers)?
Show answer

Because each layer already has a temporal dimension of length Tx, the effective depth is layers × Tx. This makes deep RNNs very expensive to train in both time and memory. In practice, a few layers already give most of the benefit, and going deeper rarely pays off.
